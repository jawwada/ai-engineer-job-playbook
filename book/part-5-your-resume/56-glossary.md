# 56. Glossary

Short definitions for the terms used across the book, alphabetical. The chapter in brackets goes deeper. Product names are as of October 2026; where a product was renamed, the former name has a short entry pointing to the current one.

- **A2A (Agent2Agent)** — protocol for agents to discover each other (agent cards) and exchange tasks across vendors; v1.0 in March 2026, part of the Agentic AI Foundation since August 2026 [14, 22, 28b].
- **Abstention** — the model declining to answer when evidence is insufficient; measured as a behavior in RAG evals, not treated as a failure [24, 24c, 32].
- **Accrual / true-up** — an accrual books an estimate of a closed month's cloud expense before the invoices are final (usage on the billed basis, prepaid purchases from their own amortization schedule); the true-up is the difference booked in a later month when the actual charges arrive [47a, 47c].
- **ACL (access control list)** — per-document or per-row permissions; carried into indexes so retrieval respects them [30].
- **ACP** — two different protocols share the initials: the Agent Client Protocol (editors hosting coding agents) and the Agentic Commerce Protocol (agent checkout); see both [23, 52a].
- **Active series** — the metric series that have received samples recently and are held in memory (Prometheus's head block, Mimir's ingesters); memory and per-series pricing scale with them, so they grow with label cardinality and churn rather than with sample rate [29b, 45a, 45b].
- **Adaptive RAG** — classifying a query's complexity first and routing it to no retrieval, a single retrieval pass or multi-step agentic retrieval; the original trained a small classifier on labels derived from which strategy answered each question correctly [24b, 24c].
- **ADK (Agent Development Kit)** — Google's open-source, code-first agent framework (Python, Go, Java, TypeScript); deploys to Agent Runtime on the Gemini Enterprise Agent Platform [15, 20].
- **Agent (AI agent)** — a language model running in a loop with tools: it chooses an action, observes the result and decides the next step until the goal is met or a budget runs out; contrast with a workflow, where your code decides the path [0, 22].
- **Agent Assist** — Google's real-time suggestions, summaries and knowledge for human contact-center agents, part of Gemini Enterprise for Customer Experience [28, 41].
- **Agent Bricks** — Databricks' managed builder for eval-optimized agents over governed data [21].
- **Agent card** — A2A's JSON descriptor advertising an agent's skills, endpoint and auth requirements [22, 28b].
- **Agent Client Protocol (ACP)** — Zed's open protocol that lets an editor host an external coding agent such as Gemini CLI or Claude Code; not to be confused with the Agentic Commerce Protocol [52a].
- **Agent Engine** — Google's former name for Agent Runtime [15].
- **Agent harness** — see Harness (agent harness) [52a].
- **Agent Identity / Agent Gateway / Agent Registry (Google)** — the governance layer of the Gemini Enterprise Agent Platform: a SPIFFE-based principal per agent, a gateway that applies IAM, semantic-governance and Model Armor policies to agent traffic in and out, and a catalog of agents and tools [30, 39b].
- **Agent Registry (AWS)** — AgentCore's governed catalog for discovering and governing agents, tools, MCP servers and skills across an organization [15, 30].
- **Agent Runtime** — the managed runtime of Google's Gemini Enterprise Agent Platform (formerly Agent Engine): deploys ADK, LangGraph, CrewAI or LlamaIndex agents with autoscaling, Agent Sessions, Memory Bank, Agent Identity and tracing [15, 39b].
- **Agent Search** — Google's managed search and RAG product for websites and enterprise documents, with access-controlled data stores and the Ranking and Check Grounding APIs (formerly Vertex AI Search) [15, 24b, 39b].
- **Agent Skills / SKILL.md** — an open format, developed by Anthropic and an open standard since December 2025, that packages a procedure as a folder: a `SKILL.md` file with YAML frontmatter (name, description, optional allowed tools and invocation rules) plus scripts and references, loaded on demand by progressive disclosure; most harnesses now load the same folders, and Gemini's skills import them [15, 45c, 52a, 60].
- **AgentCore** — AWS's managed agent infrastructure: Runtime, Harness, Gateway, Memory, Identity, Policy, Observability, Evaluations and Optimization, plus the AWS Agent Registry; verify the current list, it changes quarterly [15].
- **Agentforce / Copilot Studio** — Salesforce's and Microsoft's low-code agent platforms [28, 60].
- **Agentic AI Foundation (AAIF)** — the Linux Foundation's home, since December 2025, for open agent standards: MCP, Block's goose and OpenAI's AGENTS.md at launch, with A2A joining in August 2026 [14, 20b, 52a].
- **Agentic Commerce Protocol (ACP) / AP2 / UCP / x402 / MPP** — protocols for agent-initiated purchases and payments: OpenAI and Stripe's ACP, Google's Agent Payments Protocol, the Universal Commerce Protocol with Shopify and other retailers, and the HTTP 402 micropayment protocols x402 (Coinbase) and MPP (Stripe and Tempo); study the delegation and confirmation steps [23, 60].
- **Agentic RAG** — retrieval decided and iterated by the model rather than a fixed single pass [24, 24b].
- **AGENTS.md** — a plain-markdown instructions file read by many coding agents (Codex, Copilot, Cursor, Amp, opencode and others), the cross-vendor counterpart of `CLAUDE.md`; contributed to the Agentic AI Foundation, and read by Claude Code when a project has no `CLAUDE.md` [52a].
- **Agentspace** — Google's former name for Gemini Enterprise [15].
- **Aggregation temporality** — whether a counter or histogram point reports the change since the last export (delta) or the running total since a fixed start (cumulative); cumulative survives a lost export and is what Prometheus expects, so delta streams are converted, for example by the Collector's `deltatocumulative` processor [29b, 45b].
- **AI Search (Databricks)** — Databricks' managed index synced from Delta tables, with vector, full-text and hybrid search governed by Unity Catalog; called Vector Search until June 2026 [21].
- **AI SRE agent** — an agent that investigates alerts and incidents by forming hypotheses, querying metrics, logs, traces and recent changes, and citing the evidence behind each claim (Grafana Assistant, Datadog Bits AI SRE, PagerDuty's SRE Agent and startups); accuracy figures are vendor-reported, so evaluate on replayed past incidents with read-only credentials [45a, 45c].
- **ALAR (adaptive latent agentic reasoning)** — a 2026 method for tool-using agents in which the policy chooses each turn between a block of four continuous thoughts (about the cost of four tokens) and a written chain of thought, trained by action-anchored self-distillation and reinforcement learning; it cut generated tokens by 84.6% on single-request function calling, most of which text pruning also achieves [22c].
- **Alertmanager** — the Prometheus component that receives alerts, deduplicates, groups, silences and inhibits them, and routes notifications to receivers through a routing tree with timing settings; run as a cluster, with every Prometheus or ruler pointed at all replicas [45b].
- **Alloy (Grafana Alloy)** — Grafana Labs' OpenTelemetry Collector distribution with built-in Prometheus pipelines, configured as wired components; it replaced Grafana Agent and Promtail and can run standard Collector configuration in an experimental engine [45a, 45b].
- **Amazon Kendra / Amazon Q Business** — AWS services closed to new customers in 2026 (Kendra went into maintenance on 30 June and closed to new customers on 30 July); AWS points to the Bedrock Managed Knowledge Base and to Amazon Quick [15, 50].
- **Amortized cost** — cost with upfront and recurring commitment fees spread over the hours of usage they cover and the unused part shown separately, so it follows usage rather than payment dates; the basis for trends, showback and forecasts, and after negotiated discounts it becomes net amortized cost [47a, 47b].
- **ANN (approximate nearest neighbor)** — fast similarity search with a recall trade-off (HNSW, IVF, PQ, DiskANN) [18].
- **Annual operating plan (AOP)** — the fiscal-year plan leadership approves, with revenue, headcount and expenses by cost center and month; built two to four months before the year from the run-rate, business drivers and known projects, it becomes the budget once approved [47a, 47c].
- **Anomaly cost %** — FinOps Foundation KPI: the cost of confirmed anomalies ÷ total spend, with bands of below 2% green, 2–7% yellow and above 7% red; reported beside time to detect, time to resolve and alert precision [47d].
- **Answer relevancy** — a RAGAS metric: a judge writes questions the response would answer (three by default), and the score is their mean cosine similarity to the user's input, or 0 for a noncommittal response; it penalizes incomplete or padded answers and is comparable only under one embedding model [24c].
- **Apdex** — a 0–1 score against a target time T: requests within T count as satisfied, within 4T as tolerating (half credit), and slower or failed ones as frustrated; it hides the shape of the tail, so report it only beside percentiles [29b, 45b].
- **Approval binding** — recording a human approval against a digest of the canonical call (tool, arguments, principal, target), rendering the reviewer's screen from that same form and refusing to execute unless a fresh digest matches, one use per approval; approvals stored as yes/no flags let a reviewed \$40 refund run as \$4,000 [23b, 53c].
- **ARES** — a RAG evaluation framework (Stanford, NAACL 2024) that fine-tunes small judges on synthetic positives and negatives for context relevance, answer faithfulness and answer relevance, then corrects them with prediction-powered inference on about 150 or more human labels to put confidence intervals on system rankings [24c].
- **Argo CD** — GitOps controller that reconciles Kubernetes state from Git [45].
- **ARR / run-rate** — the latest month or quarter of revenue multiplied out to a year; not audited annual revenue, and companies define it differently; in FinOps, run-rate is the current spending level extrapolated over a stated window (a daily average × days), a baseline for a forecast rather than a forecast [0, 47a].
- **ASR / STT / TTS** — automatic speech recognition (speech-to-text) and text-to-speech; the chained voice stack's two ends [41].
- **AST (Audio Spectrogram Transformer)** — ViT applied to spectrograms for audio tagging [17].
- **Authority record** — the record of who granted an agent what, for which purpose, until when and through which chain of actors, joined to the activity log by a grant id stamped on every action; in most agent stacks only the first hop, the user's OAuth consent, leaves such evidence [23b].
- **Auto memory (Claude Code)** — notes Claude Code writes for itself per repository (an index plus topic files) and loads at session start; context, not enforced configuration [52a].
- **Autoclass** — Google Cloud Storage's automatic tiering: objects not read for 30 days move to Nearline, after 90 days to Coldline and optionally after 365 to Archive, and back to Standard when read, with no retrieval or early-deletion fees but a per-object management fee; objects under 128 KiB stay in Standard [47e].
- **Autoencoder / VAE** — networks that compress and reconstruct inputs; reconstruction error flags anomalies; the variational version yields a sampleable latent space [17].
- **Autonomy levels** — a graded scale of how much an agent may do without a person, chosen per action rather than per agent: from suggesting, through acting with approval, to acting alone and reporting; one taxonomy (Feng, McDonald and Zhang, 2025) names five levels by the user's role, from operator to observer, and each rung needs the controls of the rungs below it [53c].
- **Azure AI Foundry** — Microsoft's former name for Microsoft Foundry [15].
- **Azure Hybrid Benefit** — applying on-premises Windows Server or SQL Server licenses with Software Assurance (or qualifying subscriptions) to Azure so the resource pays only the base compute rate; Windows Server needs at least 8 core licenses per VM, and SQL Server licenses convert at fixed ratios (one Enterprise core covers four General Purpose vCores) [47e].
- **Backoff (exponential, with jitter)** — growing retry delays with randomness so retries do not stampede a recovering service [49].
- **Backtracking** — depth-first search over partial solutions that undoes each choice after exploring it and prunes branches that cannot lead to a valid answer; the pattern behind Sudoku, N-Queens and combination sums [39d].
- **Baggage** — W3C key-value pairs propagated with the trace context to every downstream service, third parties included; not added to spans unless a processor copies them, useful for per-tenant or per-feature cost roll-ups, and never a place for secrets or personal data [29b, 45b].
- **Bandit** — online allocation among options balancing exploration and exploitation; the lightweight alternative to a full A/B test [17, 36].
- **Barge-in / endpointing** — the caller interrupting the agent mid-utterance; detecting when a speaker has finished; both depend on voice-activity detection [28, 41].
- **Batch API** — asynchronous, discounted model inference for offline workloads [16, 31].
- **BilledCost / EffectiveCost / ContractedCost / ListCost** — the four FOCUS cost columns: the invoiced amount (from FOCUS 1.2 it sums to the invoice by `InvoiceId`); the amortized cost after all discounts plus the share of prepaid purchases (zero on `Purchase` rows); price × quantity at contracted prices (negotiated but not commitment discounts); and the same at list prices; exclude purchase rows when summing the last two [47a, 47b].
- **Binary search on the answer** — searching the range of possible answers for the smallest (or largest) value whose feasibility check passes; valid only when feasibility is monotone, as in minimum eating speed or ship capacity [39d].
- **Blended cost** — an AWS cost metric that averages rates across the accounts of a consolidated billing family; it hides which account benefited from a commitment, so it is rarely the right number [47a].
- **BM25** — lexical ranking function used by keyword search engines [18].
- **Bootstrap confidence interval** — resampling the evaluated items with replacement many times to put an interval around a metric; with paired tests on the same items, the honest way to report a judge-scored comparison [32b].
- **Break-even utilization** — the utilization at which a commitment costs the same as on-demand: 1 − discount (70% for a 30% discount); by the same logic each further layer pays off only if usage exceeds it in at least that share of hours, so commitments are sized from a low percentile of usage, not the average [47, 47e].
- **Burn rate** — the observed error ratio divided by the error budget (one minus the SLO): at 1 the budget lasts exactly the SLO window, at b it is gone in window ÷ b, so 14.4 empties a 30-day budget in 50 hours [29b, 45a].
- **BYOL (bring your own license)** — using licenses you already own in the cloud instead of license-included prices; rules differ by cloud and product (on AWS, Windows Server only on Dedicated Hosts and for licenses bought before October 2019; SQL Server through License Mobility with Software Assurance; on Azure, through Azure Hybrid Benefit), so decisions need the license owner [47e].
- **CAG (cache-augmented generation)** — preloading the whole knowledge base into the context, computing its KV cache once and answering without retrieval, truncating back to the cached prefix between queries; it needs a corpus that fits the window, self-hosted cache access (prompt caching on hosted APIs) and a separate cache per permission set [24c].
- **Canary / shadow deployment** — releasing to a small traffic slice, or mirroring traffic to a new model without serving its output, before promotion; a canary gate that compares the SLI between canary and stable catches gross regressions within minutes and leaves subtle ones to burn-rate alerts [45, 45a, 46].
- **Canary token** — see Tripwire / canary token [53c].
- **Capacity gap (distillation)** — the finding that a student learns less from a teacher whose distribution it cannot represent, so a smaller or differently trained teacher, or an intermediate teacher assistant, can yield the better student; run a small teacher bake-off before distilling [26c].
- **Cardinality** — the number of distinct values of an attribute, or of series a metric produces: the product of its labels' distinct values times the series per label set (17 for a classic histogram with 14 bucket boundaries); unbounded labels such as user or request ids explode memory and cost, so they belong on spans and logs [29b, 45a, 45b].
- **Cascading failure** — one agent's or service's error propagating through others that trust its output; OWASP's ASI08 for agents [30, 53c].
- **Cedar / OpenFGA / OPA** — authorization policy languages and engines (AWS Verified Permissions and AgentCore Policy use Cedar; OpenFGA is relationship-based; OPA evaluates Rego policies) [30, 53b].
- **Chain of thought (CoT)** — the model's step-by-step reasoning text before an answer; each step adds serial computation but must pass through one sampled token, and the text is a cheap but fragile window for oversight [22, 22c].
- **Chain-of-thought distillation** — training a student on a teacher's reasoning traces, not only its answers, so it produces the intermediate steps itself (DeepSeek-R1-Distill, s1, OpenThoughts); it buys accuracy with longer outputs, small students learn better from shorter chains, and closed models return only summarized or encrypted thinking [26b, 26c].
- **Chain-of-thought monitorability** — the ability to oversee a model by reading its written reasoning, which works because hard tasks force reasoning into text and models tend to write it anyway; reinforcement-learning drift, optimization pressure on the chain and latent-reasoning architectures can erode it [22c, 62].
- **Checkpointer** — persistence of graph state between steps (LangGraph) enabling resume and interrupts [20].
- **Chunking** — splitting documents into retrievable units with context and metadata [18, 24, 24c].
- **Circuit breaker / dead-letter queue** — stop calling a dependency that keeps failing; park messages that failed processing for inspection and replay [49].
- **Citations** — evidence references in an answer; the mechanism is carrying chunk ids from retrieval through generation and verifying each quoted span exists [24, 24c, 32].
- **Claude Agent SDK / Claude Managed Agents** — the harness behind Claude Code as a Python and TypeScript library you host (formerly the Claude Code SDK), and Anthropic's hosted version of it, in public beta since April 2026 and billed as tokens plus active session-hours [15, 52a].
- **Client ID Metadata Documents (CIMD)** — MCP's way for a client to identify itself to an authorization server with an HTTPS URL that serves its metadata, instead of registering dynamically; added in the 2025-11-25 revision, and Dynamic Client Registration was deprecated in its favour in 2026-07-28 [20b].
- **CLIP / SigLIP / SAM** — image-text embedding models and the Segment Anything model; the vision building blocks of multimodal pipelines [17.3].
- **CMEK** — customer-managed encryption keys; a common enterprise requirement for AI services [30].
- **Coconut (continuous thought)** — Meta's continuous chain of thought (December 2024): between special markers the last hidden state is fed back as the next input embedding instead of being decoded into a token, so one thought can hold several candidate steps; it beat written chains on graph planning but trailed them on grade-school math [22c].
- **ColBERT / late interaction** — retrieval that keeps one vector per token for query and document and scores with MaxSim (the sum of each query token's best match); more precise than single-vector search and cheaper than a cross-encoder at query time, but costly in storage; ColPali applies it to page images [18, 24b, 24c].
- **Collector (OpenTelemetry Collector)** — the vendor-neutral process that receives, processes and exports telemetry through pipelines of receivers, processors, exporters and connectors; usually deployed as a node agent plus a gateway tier for tail sampling, redaction and routing, with `memory_limiter` first in every pipeline [29b, 45b].
- **ColPali / ColQwen** — page-image retrieval: a vision-language model embeds each rendered page as one vector per image patch and scores it against the query's token vectors with late interaction (MaxSim), skipping OCR and layout parsing; strong on slides, charts and scans, with page-level citations and large indexes [18, 19, 24b, 24c].
- **Commitment discount waste** — unused commitment cost ÷ total commitment cost, which equals one minus utilization; it appears on amortized data as unused-reservation or unused-savings-plan rows (FOCUS `CommitmentDiscountStatus` = `Unused`) [47b, 47e].
- **Compaction** — summarizing older context so an agent's window stays small across long runs; the summary is written by a model that has read untrusted content and is then treated as ground truth, so handle it as an instruction channel [22b, 23b, 52a].
- **Composite availability** — the availability of a request path built from components: serial dependencies multiply (four components at 99.9–99.99% can land near 99.8%), redundant replicas help only as far as their failures are independent and the failover path works; turning hard dependencies into soft ones is the main lever [45a].
- **Compute Flexible CUDs** — Google Cloud's broad spend-based commitment: one hourly commitment covering Compute Engine, GKE Standard and Autopilot, and Cloud Run, so it follows workloads across machine families and regions; the counterpart of AWS Compute Savings Plans [47e].
- **Computer use** — a model driving a browser or desktop from screenshots and actions; slow and brittle, so used where no API exists [23].
- **Connector (OpenTelemetry Collector)** — a Collector component that is the exporter of one pipeline and the receiver of another, such as `span_metrics` turning every span into RED metrics before sampling, or a router that splits data by tenant [29b, 45b].
- **Containment rate** — share of conversations resolved without a human; the voice and support agents' headline metric, paired with CSAT [28, 41].
- **Context caching / prompt caching** — reusing a stable prompt prefix at reduced cost [16, 31].
- **Context distillation** — training a model to behave without a prompt as it does with it, by minimizing the divergence between its prompted and unprompted outputs, which bakes a long, stable system prompt or set of examples into the weights; the rules stop being readable, so version the prompt and the adapter together [26c].
- **Context engineering** — deciding what goes into the model's window each turn [22].
- **Context precision** — a rank-aware score of how many retrieved chunks are useful for the reference answer, computed as average precision over the useful chunks retrieved; it ignores useful chunks that were never retrieved, so report it with context recall [24c].
- **Context recall** — the share of the reference answer's statements that can be attributed to the retrieved contexts: did retrieval bring back everything the answer needed? It needs a reference answer [24c].
- **Context window** — the maximum tokens a model attends to per call [16].
- **Contextual retrieval** — an LLM writes a short, chunk-specific context from the whole document and prepends it to the chunk before both embedding and BM25 indexing; in Anthropic's study it cut retrieval failures by about half, and by two thirds with reranking; contextual chunk headers (title, summary, heading path) are the cheaper deterministic cousin [18, 24, 24c].
- **Conversational Agents (Google)** — the name Google used for a while for Dialogflow CX and its console; see Dialogflow CX [28, 39c].
- **Corrective RAG (CRAG)** — a lightweight evaluator grades each retrieved document and triggers an action for the query: refine the relevant passages, discard them and fall back to a rewritten search, another index or the web, or combine both when unsure; not to be confused with Meta's CRAG benchmark, which scores answers +1, +0.5, 0 and −1 so that abstaining beats a wrong answer [24b, 24c].
- **Cost Anomaly Detection (AWS)** — AWS's free machine-learning monitors by service, account, cost category or tag, run about three times a day on net unblended (not amortized) cost and reporting up to ten root-cause contributors; thresholds need tuning per monitor, and it knows nothing of planned changes or unit costs [47b, 47d].
- **Cost Categories (AWS)** — rule-based business dimensions (team, product, environment) built from accounts, services, tags, charge types and other categories, with inherited values, a default for unmatched cost and split charges; rules can apply up to 12 months back, and the same groups define Reserved Instance and Savings Plans group sharing [47b, 47d].
- **Cost Optimization Hub (AWS)** — AWS's console that consolidates rightsizing, idle-resource and commitment recommendations, counting one action per resource (the largest saving) and de-duplicating commitments against rightsizing; its Cost Efficiency metric is (1 − potential savings ÷ optimizable spend) × 100 on net amortized cost [47b, 47e].
- **Cost per completed task** — everything spent on a task class (model tokens, tools and the human time to fix or retry failures) divided by the tasks actually completed; the unit for choosing effort levels, models and harnesses, since a pricier setting with a higher completion rate can be two to three times cheaper per completed task [23b, 31].
- **Cost per span / cost per trace** — cost as a derived telemetry signal: the units on a span (uncached input, cache-read, cache-write and output tokens; compute seconds; request units; bytes) × a versioned price valid when it ran, summed per trace over inference spans only with every retry counted; compute it before sampling or weight stored traces by their adjusted count [29b, 31].
- **Coverage (commitment coverage)** — covered eligible usage ÷ total eligible usage, in on-demand-equivalent dollars (or hours for resource-based commitments): how much of what could be covered is covered; the FinOps maturity examples run from about 60% (Crawl) to over 80% (Run) [47, 47a, 47e].
- **CrewAI / AutoGen / Semantic Kernel / PydanticAI / LlamaIndex / OpenAI Agents SDK** — other agent frameworks; AutoGen and Semantic Kernel converged into the Microsoft Agent Framework [20].
- **Cross-encoder / reranker** — a model scoring query–document pairs jointly for precise ranking [18, 24b].
- **CSAT / AHT** — customer-satisfaction score; average handle time [41].
- **CTR / QPS** — click-through rate; queries per second [36.3].
- **CUD (committed use discount)** — Google Cloud's commitments: resource-based CUDs for vCPUs, memory, GPUs and other resources in a region (up to 57%, 70% for memory-optimized machines) and spend-based CUDs per service, whose new data model shows the discount as a lower usage price; purchased commitments cannot be canceled [47a, 47b, 47e].
- **CUR 2.0 (Cost and Usage Report)** — AWS's line-item billing export and its source of record for cost, delivered through Data Exports with a fixed schema and nested map columns (`product`, `resource_tags`, `cost_category`, `discount`); amortization depends on the line item type, and filtering on `Usage` alone drops commitment-covered usage [47a, 47b].
- **Customer Engagement Suite (CES)** — Google's former name for Gemini Enterprise for Customer Experience [28, 41].
- **CX Agent Studio (Customer Experience Agent Studio)** — Google's current builder for contact-center agents inside Gemini Enterprise for Customer Experience, documented as the evolution of Dialogflow CX: LLM agents with instructions, tools, callbacks and guardrails that can hand a conversation to existing Dialogflow CX flows [28, 39c, 41].
- **Cyclic sort** — placing each value of a 1..n range at index value − 1 by swapping, in O(n) time and O(1) extra space, so missing and duplicated values show up at the wrong indices [39d].
- **Cypher / GQL** — query languages for property graphs [25, 33].
- **Data Exports (AWS)** — the AWS Billing service that writes CUR 2.0, FOCUS 1.2 and other cost exports to S3 as Parquet or CSV at least daily; the previous month can still change for two weeks after it ends, and create-new delivery mode double-counts unless only the latest delivery is read [47a, 47b].
- **Database Savings Plans** — AWS's spend-based commitment for databases (December 2025; one year, no upfront) covering Aurora, RDS, DynamoDB, ElastiCache and other services, up to 35% off serverless and 20% off provisioned usage; it cannot be combined with RDS Reserved Instances on the same workload, and Azure's counterpart is the savings plan for databases [47e].
- **Deep Agents** — LangChain's harness package: planning tool, file-system memory, sub-agents, skills middleware [22b].
- **Dialogflow CX** — Google's flow-based plus generative conversational platform (flows, pages, intents, entities, playbooks, data stores), branded Conversational Agents for a while; Google now files it under legacy conversational agents — still documented and running — with CX Agent Studio as its evolution [28, 39c, 41].
- **Diffusion / flow matching** — generative models that learn to reverse noise (or a straight transport path) into data; the basis of image, audio and video generation [17.5].
- **Dijkstra's algorithm** — single-source shortest paths in a graph with non-negative edge weights, using a min-heap of tentative distances and skipping stale entries; O((V + E) log V) [39d].
- **DINOv3** — Meta's self-supervised image encoder (August 2025): a 7-billion-parameter ViT trained on 1.7 billion curated images with self-distillation, masked-latent prediction and Gram anchoring to keep patch features sharp, distilled into smaller models; the usual frozen backbone for appearance and dense tasks, where it beats V-JEPA encoders [17b].
- **Distillation** — knowledge distillation: training a student model to reproduce a teacher's behavior from its outputs, token probabilities, hidden states, rationales or trajectories, on sequences written by the teacher (off-policy) or by the student and scored by the teacher (on-policy); the richer the signal, the more access to the teacher it needs [26b, 26c].
- **Distillation attack** — extracting a closed model's capabilities by generating training data through many accounts in breach of its terms; Anthropic's February 2026 disclosure attributed over 16 million exchanges through about 24,000 fraudulent accounts to DeepSeek, Moonshot AI and MiniMax, and providers detect it with classifiers and behavioral fingerprinting [26c].
- **Document parsers (Docling, Unstructured, LlamaParse; Document AI, Document Intelligence, Textract)** — open-source and cloud services that turn PDFs and scans into structured text, tables and layout [19, 24].
- **DPO (direct preference optimization)** — aligning a model on preference pairs without a reward model [26b].
- **Draft model (speculative decoding)** — the small model, or extra decoding heads such as Medusa and EAGLE, that proposes tokens for the target to verify; a drafted token is accepted with probability 1 − TV(p, q), so the draft is distilled to match the target's distribution, and its acceptance rate on your own traffic sets the speedup [16, 26c].
- **Drift** — change in input or output distributions over time that degrades models [46].
- **Driver-based forecast** — a forecast built as a fixed base plus unit cost × volume for each business driver (orders, users, data, headcount), plus known changes from engineering weighted by confidence, minus probability-weighted savings and planned commitment savings; the forecast you can defend line by line [47c, 47e].
- **DSPy / GEPA** — programmatic prompt optimization: a framework that compiles prompts against an eval metric, and a reflective evolutionary optimizer [22b, 60].
- **Durable execution (Temporal)** — workflows whose state survives crashes because each step is recorded in an event history, journal or checkpoint store and replayed on recovery (Temporal, Restate, Inngest, DBOS); the backbone for long-running agent jobs, though history and payload caps mean long agent transcripts should be stored by reference [14, 20, 23b].
- **Dynamic programming** — solving a problem from the answers to overlapping subproblems, each computed once, either top-down with memoization or bottom-up in a table; state, transition, base cases and iteration order define it [39d].
- **eBPF instrumentation (OBI)** — kernel-verified probes that observe system calls, network traffic and function calls without changing or restarting the application; OpenTelemetry eBPF Instrumentation (OBI, donated from Grafana's Beyla and still at v0) emits spans and RED metrics for HTTP, gRPC, SQL and other protocols, but sees protocols, not business context [29b, 45b].
- **EDP / PPA** — AWS's Enterprise Discount Program or Private Pricing Agreement: a commitment to a level of AWS spend over a term in exchange for a discount across most services; it shows as negative discount lines (or in the `discount` column) and in the `net_` cost columns, and it stacks with Savings Plans and Reserved Instances [47a, 47e].
- **Effective savings rate (ESR)** — the share saved by discounts, with three definitions to name beside any number: the FinOps Foundation's commitment savings net of unused commitment ÷ on-demand-equivalent spend (about utilization × coverage × discount); FOCUS's (`ContractedCost` − `EffectiveCost`) ÷ `ContractedCost`; and vendors' 1 − actual ÷ on-demand-equivalent spend [47a, 47b, 47e].
- **Elasticity (price)** — percentage change in demand per percentage change in price; the quantity pricing models estimate [36.3, 36.4].
- **Elicitation (MCP)** — an MCP server asking the user a structured question mid-call ("which of these accounts did you mean?"); since the 2026-07-28 revision delivered through multi round-trip requests [20b].
- **EMA target encoder** — a target network whose weights are an exponential moving average of the online encoder's and receive no gradient (stop-gradient); with a predictor on the online side, this asymmetry prevents collapse in BYOL, DINO and the I-JEPA and V-JEPA family [17, 17b].
- **Embedding** — a vector representation capturing meaning for similarity search [18].
- **Energy-based model (EBM)** — a model that assigns a scalar energy to each input–output pair, low for compatible ones, and infers by minimizing energy rather than sampling a normalized distribution; trained contrastively or with regularizers, and a JEPA is one whose energy is prediction error in representation space [17b].
- **Error budget** — one minus the SLO, counted in events or time (a 99.9% SLO over 30 days allows 43.2 minutes of full outage, or one failure per thousand valid requests); an error-budget policy signed by engineering and product says what changes when it runs low or out, such as pausing feature releases [29b, 45a].
- **EU AI Act** — EU regulation with risk-tiered obligations (prohibited practices, general-purpose models, transparency, high-risk systems) phasing in from 2025; the 2026 Digital Omnibus moved the high-risk dates to December 2027 and August 2028 [30, 53b, 54b].
- **Eval set / gold set** — curated inputs with references or rubrics used to measure quality [32].
- **Evaluator–optimizer** — a generate–critique–revise loop with explicit criteria [22].
- **Exemplar** — a single raw measurement attached to an aggregated metric point, carrying the trace and span ids of the request behind it, so a dashboard can jump from a slow histogram bucket to the trace; SDKs keep exemplars from sampled traces by default [29b, 45b].
- **Exponential histogram** — an OpenTelemetry histogram whose bucket boundaries are powers of a base set by a scale, so relative precision is the same at 1 ms and at 100 s and histograms with compatible scales merge exactly; Prometheus stores them as native histograms [29b, 45b].
- **Extended thinking** — Claude's visible reasoning mode with a token budget; the unit of the "reasoning as a budget" trend [16, 39b].
- **Faithfulness / groundedness** — whether an answer is supported by the retrieved evidence, judged claim by claim; RAGAS scores it as supported statements ÷ all statements, which measures grounding, not correctness: an answer faithful to a stale chunk scores 1.0 [24c, 32].
- **Fast and slow pointers** — two pointers moving one and two steps at a time (Floyd's cycle detection); they meet inside a cycle if one exists, and a second walk from the head finds the cycle's entrance; also finds the middle of a list [39d].
- **Favorable / unfavorable variance** — for costs, spending below plan is favorable (F) and above it unfavorable (U); teams differ on whether they print actual − plan or plan − actual, so agree the convention with finance and print F or U beside every number [47a, 47f].
- **FDE (Forward Deployed Engineer)** — engineer embedded with customers to take AI use cases to production [44].
- **Feature store** — versioned, point-in-time-correct features shared by training and serving to prevent skew [46, 48].
- **Few-shot / zero-shot** — prompting with or without worked examples [22].
- **Fine-tuning** — updating a pre-trained model's weights (fully or through adapters) on task data; the last resort after prompting and retrieval plateau [26, 27].
- **FinOps** — the practice of managing cloud and AI spend across engineering, finance and product; the FinOps Foundation's 2026 Framework groups 22 capabilities into four domains across the Inform, Optimize and Operate phases [31, 47, 47a].
- **FinOps hubs (FinOps toolkit)** — the data layer of Microsoft's open-source FinOps toolkit: Cost Management exports in FOCUS ingested into storage, Azure Data Explorer or Microsoft Fabric, with Power BI reports and added columns such as Hybrid Benefit status; not to be confused with Google Cloud's FinOps hub of usage insights [47b, 47e].
- **FLARE** — forward-looking active retrieval: the model drafts its next sentence and, if any token's probability falls below a threshold, retrieves with that sentence (uncertain tokens masked or turned into questions) and regenerates; it needs access to token probabilities [24c].
- **FOCUS (FinOps Open Cost and Usage Specification)** — the vendor-neutral schema for billing data, with standard columns such as `BilledCost`, `EffectiveCost`, `ChargeCategory`, `ServiceCategory` and `SubAccountId` and an `x_` prefix for provider extras; all three clouds now export it (Google Cloud's export in preview), so one table can hold every cloud, but versions are not column-compatible, so pin one [47, 47a, 47b].
- **Forecast accuracy rate / forecast drift rate** — FinOps Foundation forecasting KPIs: (forecast − actual) ÷ forecast for a period, and (new forecast − previous forecast) ÷ previous forecast, which shows how far each reforecast moved; report them by cloud as well as in total, because totals hide offsetting misses [47c].
- **Fork bomb (agentic)** — agents spawning helpers that spawn helpers, from an injected instruction or unprompted over-delegation; a depth cap bounds the height, a concurrency cap the width, and only a spend cap the total [53c].
- **Forward KL / reverse KL** — the two directions of the distillation divergence: KL(teacher‖student) averages over teacher samples and makes the student cover every teacher mode (mode covering; what soft targets and SFT minimize, natural for classifiers), while KL(student‖teacher) averages over the student's own samples and lets it commit to modes it can represent (mode seeking; natural for on-policy post-training of generators) [26c].
- **Function calling / tool use** — a model emitting structured calls to functions you execute [20, 28b].
- **GDPR / CCPA / HIPAA / PII / PHI** — the EU and California privacy laws, the US health-privacy law, and the data classes they protect (personally identifiable and protected health information) [30, 59].
- **Gemini Enterprise** — Google's employee-facing app for enterprise search, assistants and agents with permission-aware connectors (formerly Agentspace); not the developer platform [15, 23, 60].
- **Gemini Enterprise Agent Platform** — Google Cloud's platform for building, deploying, governing and evaluating models and agents: Model Garden, ADK and Agent Studio, Agent Runtime, Agent Search, Agent Identity, Gateway and Registry, evaluation and pipelines; the April 2026 successor brand of Vertex AI, whose API endpoint (`aiplatform.googleapis.com`) it kept [15, 39b].
- **Gemini Enterprise for Customer Experience** — Google's contact-center suite (formerly the Customer Engagement Suite): CX Agent Studio, the legacy Dialogflow CX, Agent Assist, Customer Experience Insights, telephony, and prebuilt shopping and food-ordering agents [28, 39b, 41].
- **Gemini Gems** — customized versions of Gemini (a name, instructions and optional files) shared like Drive files; from November 2026 Google is converting them into Gemini skills, which can import `SKILL.md` folders but cannot run scripts that reach external sites [45a, 45c].
- **GitOps** — infrastructure and deployments declared in Git and reconciled by a controller [45].
- **GKD (generalized knowledge distillation)** — an on-policy method (Agarwal et al., ICLR 2024) that mixes student-generated and fixed-dataset batches and uses a generalized Jensen–Shannon divergence whose parameter β moves it between forward-like and reverse-like behavior, without backpropagating through sampling [26c].
- **Golden signals** — latency (successful and failed requests measured separately), traffic, errors (explicit, implicit and by policy) and saturation: the four signals the Google SRE book says to watch on any user-facing system [29b].
- **GraphRAG** — retrieval over an extracted entity graph with community summaries for global questions [25].
- **Greedy algorithm** — making the locally best choice at each step; correct only when an exchange argument shows the greedy choice can replace any choice in an optimal solution, as with keeping the interval that ends first [39d].
- **Grokking the Coding Interview** — Design Gurus' course that organizes coding-interview problems into patterns (about forty in the current course; its April 2026 article lists twenty, the basis of chapter 39d) [39d].
- **GRPO** — group-relative policy optimization; RL with verifiable rewards used for reasoning models [26b].
- **Guardrails** — input, retrieval, tool, output and monitoring checks ("rails") that enforce policy and safety; they lower risk but do not replace authorization at the data layer [30, 53b].
- **Hallucination** — fluent output unsupported by evidence or fact; reduced by grounding, abstention and judges, never eliminated [32].
- **Harness (agent harness)** — everything around a model that makes it an agent: the loop, tools, instructions, context management (compaction, sub-agents, files as memory), permissions and sandbox, hooks, sessions and observability; the same model performs very differently in different harnesses, and most reliability gains now come from here [22b, 52a].
- **Head sampling** — deciding whether to keep a trace when its root span starts, from the trace id, and propagating the decision in the sampled flag; cheap but blind to how the request turns out, and each trace kept at probability p stands for 1/p traces (its adjusted count), so totals from stored traces must be weighted [29b, 45b].
- **HITL (human-in-the-loop)** — approval gates and review queues inside automated workflows [22].
- **HNSW** — hierarchical navigable small-world graph index for ANN search [18].
- **Hooks** — handlers that run deterministically at agent lifecycle events (before or after a tool call, at a permission decision, at session start, on notifications) and can block an action, which an instruction in `CLAUDE.md` cannot [52a, 53b].
- **Hybrid search** — combining lexical and vector retrieval, fused with RRF or, given labeled queries, a tuned weighted sum of normalized scores [18, 24c].
- **HyDE / query rewriting** — generating a hypothetical answer, or several rephrasings, to retrieve with; cheap recall improvements, best run in parallel with the raw query and fused with RRF [24, 24b, 24c].
- **I-JEPA** — Meta's first JEPA (2023), for images: a narrow predictor predicts the target encoder's embeddings of four large hidden blocks from one context block, with an EMA target and no hand-designed augmentations; strong linear-probe accuracy at a fraction of MAE's compute, with non-commercial weights [17, 17b].
- **IaC (infrastructure as code)** — Terraform/CDK/Bicep definitions of infrastructure [45].
- **Idempotency** — an operation safe to repeat without duplicate side effects [49].
- **Implicit chain of thought** — reasoning distilled from written chains into the hidden states of a model that answers directly, for example by stepwise internalization (iCoT), which removes intermediate steps gradually during training; these methods need explicit chains as the teacher signal [22c].
- **Incrementality** — causal lift measured by holdouts or geo experiments rather than attribution rules [36.3, 61].
- **Inhibition (Alertmanager)** — a rule that mutes target alerts while a source alert fires with equal values for chosen labels, such as silencing a cluster's pod alerts while the cluster is unreachable or a service's tickets while its SLO page fires [45a, 45b].
- **Injection laundering / trust laundering** — untrusted text losing its provenance on the way through a system: a sub-agent's summary carries injected instructions upward as a "finding", or a memory entry turns a claim from a tool result into a standing rule [53c].
- **Instruction channel** — any store an agent reads that someone else can write, through which instructions reach it besides the prompt: firewall logs, compaction summaries, shared spaces, instruction files on untrusted branches, skills, tool descriptions, A2A results, call transcripts, pages in a signed-in browser; inventory them and split reading from acting [23b, 30].
- **Instrumentation scope** — the name, and optionally the version, of the library or module that emitted a group of telemetry records, which tells spans from auto-instrumentation apart from those of your own code [29b].
- **Intelligent-Tiering (S3)** — an S3 storage class that moves objects not accessed for 30 days to an infrequent tier and after 90 days to an archive instant-access tier, with no retrieval fees but a small monitoring charge per object (objects under 128 KB stay in the frequent tier); Azure's counterpart is Blob smart tier and Google's is Autoclass [47, 47e].
- **Inter-rater agreement (Cohen's κ, Krippendorff's α)** — chance-corrected agreement between two or more raters; the yardstick for calibrating a judge against humans, with human–human agreement as the ceiling [32b].
- **IRCoT** — interleaving retrieval with chain of thought: each reasoning sentence becomes the next retrieval query and the retrieved paragraphs accumulate until the model answers; prompting only, with large gains on multi-hop questions [24c].
- **ISO/IEC 42001** — the certifiable AI management-system standard (2023): policy, roles, risk and impact assessment, lifecycle controls, supplier management, monitoring and audit; increasingly requested in procurement [30, 53b].
- **Jailbreak** — input crafted to bypass a model's safety behavior; tested in red-team suites [30, 53].
- **JEPA** — Joint-Embedding Predictive Architecture: a context encoder, a target encoder and a predictor that predicts the embedding of a hidden part of the input (or of the next state, given an action) instead of its pixels or tokens; an EMA target encoder or a regularizer such as SIGReg prevents collapse (I-JEPA, V-JEPA 2, LeJEPA) [17, 17b].
- **Judge cascade** — a cheap judge decides clear cases and escalates low-confidence, disputed or high-stakes items to a stronger judge or a human [32b].
- **Judge (LLM-as-a-judge)** — a model scoring outputs against a rubric, calibrated to human labels [32, 32b].
- **Judge panel / jury** — several smaller judges, ideally from different model families, aggregated by majority or mean; often matches a single large judge with less self-preference bias and at lower cost (Verga et al., 2024) [32b].
- **K-way merge** — merging k sorted sequences with a min-heap holding one head per sequence; O(N log k) for N elements; also finds the kth smallest across sorted lists [39d].
- **Kahn's algorithm** — topological sorting by repeatedly removing a node with no incoming edges and decrementing its neighbors' in-degrees; leftover nodes mean a cycle [39d].
- **Kill switch** — a control outside the agent's reach that stops an agent or a whole agent tree quickly: ask it to stop, stop the runtime and every child, and revoke its credentials at the identity provider and gateway; one on-call action, drilled regularly [53b, 53c].
- **Knapsack (0/1)** — choosing items, each at most once, under a capacity to maximize value; dynamic programming over capacities filled from high to low (filling low to high gives the unbounded variant); subset sum and equal partition reduce to it [39d].
- **KV cache** — stored attention keys/values enabling fast decoding and prefix reuse [16].
- **KV-cache sharing** — passing one model's key-value cache to another instead of a text message, so the receiver attends to the sender's computation; lossless without training only between identical weights (LatentMAS), across model families it needs a trained fuser per pair, and caches are large, can leak their inputs and are an injection path [22c].
- **Laddering (commitments)** — buying commitments in tranches, each sized to the then-current usage floor, so they expire on different dates and every quarter offers a chance to adjust; usually paired with three-year terms for the certain floor and one-year terms for the next layer [47, 47e].
- **Lakeflow** — Databricks' ingestion, pipeline and orchestration suite [21].
- **Lakehouse** — open table formats on object storage with ACID, serving BI/ML/AI from one copy [21].
- **LangGraph Platform** — LangChain's former name for LangSmith Deployment [20].
- **LangSmith / Langfuse / Phoenix / Braintrust** — LLM tracing and evaluation platforms; Langfuse and Phoenix are open source [29, 32].
- **LangSmith Deployment** — LangChain's managed runtime for LangGraph agents (cloud, hybrid or self-hosted), called LangGraph Platform until October 2025 [20, 50].
- **Late chunking** — embedding a whole document (or a long window) once with a long-context embedding model and mean-pooling the token embeddings inside each chunk's span, so every chunk vector carries document context; no LLM calls, but it improves only dense vectors and needs a model that exposes token embeddings [24c].
- **Latent reasoning** — reasoning carried by continuous vectors instead of emitted tokens: hidden states fed back as inputs, layers iterated in place, placeholder positions, or KV caches passed between models; cheaper and denser per step, but unreadable without probes or decoders; in interviews it can also mean the hidden thinking of API models [22, 22c, 39, 39b].
- **LatentMAS** — a training-free multi-agent design (ICML 2026) in which agents with identical weights reason in latent steps fed back from last-layer hidden states and pass their KV cache to the next agent as shared working memory; about four times faster than agents exchanging text, but not faster than one model answering alone [22c].
- **LatentRAG** — a 2026 agentic RAG method that computes a latent thought and a latent sub-query for placeholder tokens in one parallel pass, maps the sub-query into the retriever's embedding space and decodes only the answer, cutting latency by about 90% against explicit agentic RAG at similar accuracy; optional decoder heads recover readable queries for audit [22c].
- **Latest estimate (LE) / outlook** — actuals for closed months plus forecast for the rest of the year ("9+3" is nine months of actuals and three of forecast), compared with the budget to show how the year will land [47a, 47c].
- **Lazy deletion (heaps)** — marking removed values in a counter and discarding them only when they reach the top of a heap, so removal from the middle costs O(log n) amortized; used for sliding-window medians [39d].
- **Learning-to-rank / LambdaMART** — supervised ranking trained on relevance labels or clicks over features such as BM25, vector and reranker scores, recency and authority; LambdaMART is the gradient-boosted-tree version that optimizes NDCG [24b].
- **Least privilege** — grant only the permissions a task needs; for agents, per-tool and per-user scopes [30].
- **LeetCode** — an online judge with thousands of coding problems, numbered and tagged by topic, that interview preparation commonly uses; some problems require a Premium subscription [39d].
- **LeJEPA** — Balestriero and LeCun's JEPA recipe (November 2025) that prevents collapse with SIGReg alone, with no EMA target, stop-gradient, teacher or schedules, arguing that an isotropic Gaussian is the embedding distribution that minimizes downstream prediction risk; its training loss tracks downstream probe accuracy, which helps model selection [17b].
- **Lethal trifecta / Agents Rule of Two** — Simon Willison's warning that an agent with access to private data, exposure to untrusted content and a way to communicate externally can be made to exfiltrate; Meta's Agents Rule of Two (October 2025) generalizes it: in one session an agent should have at most two of untrusted input, access to sensitive data or systems, and the ability to change state or communicate externally, unless a human approves the step [30, 49].
- **LGTM stack** — Grafana Labs' open-source observability stack: Loki for logs, Grafana for dashboards, Tempo for traces and Mimir for metrics, usually with Pyroscope for profiles and Alloy or the OpenTelemetry Collector for collection [45a, 45b].
- **Linear probe** — a logistic regression (or difference-of-means direction) on a model's activations that scores a property such as deception or harmful intent for the cost of one dot product, calibrated at a fixed false-positive rate on benign traffic; it finds only what it was trained on and can be evaded, so never train the model against it [22c, 62].
- **Listwise reranking** — an LLM ordering a whole candidate list in one prompt (with sliding windows for long lists), as opposed to scoring items one at a time (pointwise) or in pairs (pairwise) [24b].
- **Little's law** — in any stable system, the mean number of items in flight equals the arrival rate × the mean time each spends there (L = λW), whatever the distributions: 200 requests per second at 0.25 s means 50 in flight; it sizes worker pools and GPU batch slots and prices latency in infrastructure [29b].
- **LLM gateway (LiteLLM, Portkey, Unity Gateway)** — a proxy that unifies model APIs, holds keys, routes, caches, enforces budgets and attributes cost [14, 31].
- **Logit distillation (top-k)** — matching a teacher's next-token distribution at every position, which needs a shared vocabulary; full distributions are too large to store, so teams keep the top-k or sampled logits; renormalizing a top-k slice biases the student unless the leftover mass is kept as a tail bucket, and the logits of behavior-switching tokens (tool-call opener, end of turn) should always be kept [26c].
- **Logit lens / tuned lens** — decoding an intermediate hidden state into token predictions with the model's final unembedding (logit lens: free, unreliable in early layers) or a trained per-layer map (tuned lens); decoded latent thoughts are hidden computation, not hidden explanation, so back them with causal tests [22c].
- **LogQL** — Loki's query language: a stream selector on indexed labels, then line filters, parsers (`json`, `logfmt`, `pattern`) and label filters; metric queries wrap a log query in range functions such as `rate` and `count_over_time` or unwrap a numeric field [33, 45b].
- **Loki** — Grafana Labs' log store, which indexes only a small, bounded set of labels per stream and keeps compressed log chunks in object storage; queried with LogQL, with high-cardinality fields in structured metadata [45a, 45b].
- **Long context / lost in the middle** — windows of a million tokens; the finding that models attend poorly to evidence placed mid-prompt, which is why ordering matters [16, 24, 24c].
- **LoRA / QLoRA** — low-rank adapters for parameter-efficient fine-tuning; QLoRA on a quantized base [26].
- **Lower bound (binary search)** — the first index whose value is at least the target (the array length if none); the one binary-search template from which ceiling, insert position and first/last occurrence follow [39d].
- **LSTM** — long short-term memory recurrent network; the pre-transformer sequence model still found in older intent classifiers and forecasters [17].
- **MACC (Microsoft Azure Consumption Commitment)** — a contract to spend a set amount on Azure over a term: eligible usage, prepayments such as reservations and "Azure benefit eligible" Marketplace purchases draw it down, credits do not, and a shortfall is billed, so optimization raises shortfall risk [47a, 47e].
- **Managed retrieval** — cloud services that bundle parsing, chunking, embedding, hybrid search and ACL filtering: Bedrock Knowledge Bases and the Managed Knowledge Base, Google's Agent Search and RAG Engine, Azure AI Search, Databricks AI Search [15, 24, 24b].
- **Managed settings** — Claude Code settings deployed by an administrator that user, project and command-line settings cannot override: deny rules, allowed MCP servers, telemetry, `disableBypassPermissionsMode`, and hooks or permission rules accepted only from the managed tier [52a, 53b].
- **MCP Apps / MCP extensions** — optional, versioned additions outside MCP's core, negotiated per request: Tasks (long-running work with polling), MCP Apps (interactive UI rendered in the conversation), Skills over MCP, and authorization extensions [20b].
- **MCP host / client / server** — the application the user works in (Claude Code, ChatGPT, an IDE), the connector inside it that talks to one server, and the program that exposes tools, resources and prompts [20b].
- **MCP (Model Context Protocol)** — the open standard for exposing tools, resources and prompts to models through servers; in the Agentic AI Foundation since December 2025, and stateless since the 2026-07-28 revision [20b, 28b].
- **MCP transports (stdio, Streamable HTTP)** — local servers run as child processes over standard input and output; remote servers over Streamable HTTP with OAuth 2.1 [20b].
- **Medallion** — bronze/silver/gold data-layer convention [21].
- **Memoization** — caching the results of a recursive function by its arguments so each subproblem is solved once; top-down dynamic programming (functools.cache in Python) [39d].
- **Memory Bank (Agent Memory Bank)** — long-term memory for agents on Google's Agent Runtime (formerly part of Vertex AI Agent Engine) [15].
- **Microsoft Fabric / OneLake** — Microsoft's unified analytics platform and its single logical lake [21].
- **Microsoft Foundry** — Microsoft's platform for AI apps and agents, called Azure AI Foundry until November 2025: the model catalog (OpenAI, Claude and open models), Foundry Agent Service, Foundry IQ, guardrails and the Foundry Control Plane [15, 53b].
- **Mimir** — Grafana Labs' horizontally scalable, multi-tenant long-term store for Prometheus metrics, written by remote write or OTLP, with per-tenant limits, shuffle sharding and, since Mimir 3.0, Kafka-based ingest storage [45a, 45b].
- **MiniLLM** — a distillation method (Gu et al., ICLR 2024) that minimizes reverse KL with policy gradients, stabilized by single-step decomposition, teacher-mixed sampling and length normalization, on the argument that forward KL makes a small student overrate the teacher's low-probability regions [26c].
- **Mixture of experts (MoE)** — architecture activating a subset of experts per token [16].
- **MLflow** — open-source experiment tracking, model registry, evaluation and GenAI tracing [21, 46].
- **Model Armor** — Google Cloud's prompt/response screening service [30, 39b, 53b].
- **Model-predictive control (MPC)** — planning by proposing action sequences, rolling them through a world model, scoring the predicted states with a cost, executing the first action and replanning; LeCun's "Mode-2", used by V-JEPA 2-AC with the cross-entropy method [17, 17b].
- **Model registry** — versioned store of models with stage transitions (staging, production, archived) and lineage [46].
- **Model routing** — sending requests to different model tiers by difficulty or policy [31].
- **Monitorability tax** — the cost accepted to keep a model's reasoning monitorable: for Baker et al. (OpenAI, March 2025) the performance given up by not optimizing the chain of thought directly, and for OpenAI's December 2025 study the extra inference a smaller model spends thinking longer to match a larger one while staying easier to monitor [22c, 62].
- **Monotonic stack** — a stack of indices whose values stay in increasing or decreasing order; each index is pushed and popped once, so next greater or smaller elements, spans and histogram areas take O(n) [39d].
- **Morris II / AI worm** — a self-replicating prompt (Cohen, Bitton and Nassi, 2024) that spread between RAG email assistants without a click; Prompt Infection and Agent Smith showed the same inside multi-agent systems [53c].
- **Mosaic AI** — Databricks' label for its GenAI stack (Model Serving, AI Search, Unity Gateway, Agent Framework, Agent Evaluation), which Databricks has been retiring in favour of plain product names during 2026 [21].
- **MRTR (multi round-trip requests)** — the MCP 2026-07-28 pattern that replaced server-initiated requests: the server returns `input_required` with what it needs, and the client retries the original request with the answers [15, 20b].
- **MTEB** — benchmark suite for embedding models [18].
- **MTTD / MTTA / MTTR / MTBF** — mean time to detect, to acknowledge, to repair, recover or resolve (say which, and from when), and between failures; incident durations are heavy-tailed, so report medians and percentiles over many incidents [29b, 45a].
- **Multimodal** — models consuming or producing more than one modality (text, image, audio, video) [19].
- **Multiwindow, multi-burn-rate alerting** — the SRE workbook's SLO alerting: page when both a long window and a short one (about a twelfth of it) exceed a burn rate, 14.4 over one hour and five minutes or 6 over six hours and 30 minutes, and open a ticket at 1 over three days and six hours; the long window gives significance, the short one stops the alert soon after recovery [45a, 45b].
- **Native histogram** — Prometheus's histogram stored as one series per label set with exponential buckets, instead of one series per bucket, stable since Prometheus 3.8; queries drop the `_bucket` suffix and the `le` label, and scraping must be enabled per job [29b, 45a, 45b].
- **NDCG / MRR / recall@k** — ranking and retrieval quality metrics: recall@k is the share of relevant items in the top k, MRR the mean reciprocal rank of the first relevant item, and nDCG@k the discounted gain of graded labels normalized by the ideal ordering; state the variant (gain, cutoff) next to every number [18, 24c, 32].
- **Net amortized cost** — amortized cost after negotiated discounts such as an EDP or PPA, equal to FOCUS `EffectiveCost`; the usual basis for showback, chargeback, budgets and forecasts [47a, 47c].
- **NIST AI RMF / AI 600-1** — the US voluntary AI risk-management framework (Govern, Map, Measure, Manage) and its Generative AI Profile [53b].
- **Noise sensitivity** — a RAGAS metric, lower being better: the share of response statements that are incorrect and supported by a relevant chunk (misled by noise inside useful chunks) or only by irrelevant ones (misled by distractors); its judge calls grow with the number of chunks [24c].
- **OAuth / OIDC / JWT** — delegation, identity and token formats; agents act for users through scoped tokens, never shared passwords [30].
- **OBO (on-behalf-of)** — token exchange so an agent acts with the user's permissions [30].
- **Observability** — a property of a system and its telemetry: how well logs, metrics, traces and profiles it already emits let you explain any internal state, including ones nobody anticipated, without shipping new code; monitoring answers only the questions chosen in advance [29, 29b].
- **OCR** — optical character recognition; now usually one stage inside a document-understanding model [19].
- **On-policy distillation** — the student samples completions, the teacher scores every token of them in one prefill pass, and the student is updated to reduce the per-token divergence (usually reverse KL) on its own prefixes; it fixes exposure bias with a dense signal at a fraction of RL's compute, but needs teacher log-probabilities on student text and a shared tokenizer [26c].
- **Ontology** — the schema of a knowledge graph: entity and relationship types [25].
- **OpenAPI / Pydantic / FastAPI** — the API specification format; the Python validation library; the typed async web framework [49].
- **OpenTelemetry (OTel)** — vendor-neutral telemetry standard: APIs, SDKs, the OTLP protocol, the Collector and semantic conventions (including GenAI conventions for LLM spans) for traces, metrics, logs and, in alpha, profiles [29, 29b, 45b].
- **Orchestrator–workers** — a central planner dispatching sub-tasks to workers and synthesizing [22].
- **OTLP (OpenTelemetry Protocol)** — protobuf messages for traces, metrics, logs and profiles sent over gRPC (port 4317) or HTTP (port 4318), with partial-success responses and retries on 429, 502, 503 and 504; a protocol or port mismatch between SDK and Collector fails quietly [29b, 45b].
- **OTTL (OpenTelemetry Transformation Language)** — the statement and condition language of the Collector's `transform` and `filter` processors, used to set, delete or rewrite attributes and drop records: redaction, convention renames, cost computed on spans [29b, 45b].
- **OWASP Top 10 for LLM Applications / for Agentic Applications / MITRE ATLAS** — threat catalogues: the LLM list (2026 edition, posted in August 2026, with excessive agency moved up to LLM03), the separate Top 10 for Agentic Applications (December 2025, ASI01–ASI10), and MITRE's matrix of attacks on ML systems [30, 53, 53b].
- **p95 / p99** — latency percentiles; the numbers to quote instead of averages, computed from merged histograms and never averaged across instances or added across hops [29, 29b, 45, 45b].
- **Parallel tool calls** — the model emitting several tool calls in one turn; execute concurrently and return all results [20].
- **pass^k** — success on all of k runs of the same task, a consistency metric for stochastic agents; for large k it approaches the share of tasks the agent solves every time, so reporting it beside pass@1 separates reliable tasks from lucky ones [22, 23b, 53].
- **Pause tokens** — learnable placeholder tokens appended to the input so the model computes longer before answering; they helped only when used in both pretraining and fine-tuning, and related filler-token results show useful computation can sit in positions whose tokens say nothing [22c].
- **pgvector** — Postgres extension for vector storage and search [18].
- **Playbook** — Dialogflow CX's LLM-driven, goal-oriented agent inside a flow; in CX Agent Studio the equivalent is an LLM agent [39c, 41].
- **Plugin / marketplace** — a bundle of skills, sub-agents, hooks, commands and MCP servers, installed from a marketplace (in Claude Code with `/plugin`); the way teams share a configured harness, and something to review like code [52a, 60].
- **Position bias** — a judge preferring the first (or last) candidate; mitigated by swapping order and averaging [32].
- **Post-hoc attribution (verify-then-answer)** — checking each claim of a draft against the evidence and removing or flagging unsupported ones before answering, with citations per sentence [24b, 24c].
- **Prediction-powered inference (PPI)** — combining many judge labels with a small human-labelled sample from the same distribution: the judge's mean plus a correction measured on the sample gives an unbiased estimate with a valid confidence interval (Angelopoulos et al., 2023) [32b].
- **Prefix sum** — the running total up to each index; with a hash map of earlier prefix sums it counts subarrays with a given sum even when values are negative, where a sliding window fails [39d].
- **Presidio** — Microsoft's open-source PII detection and redaction library [30].
- **Prompt injection** — instructions in input or content that try to redirect the model [30, 53].
- **PromQL** — Prometheus's query language over labeled time series: selectors, instant and range vectors, `rate` before `sum`, `histogram_quantile` over merged buckets, and vector matching with `on`, `ignoring` and `group_left`; Mimir and Thanos run it too [33, 45b].
- **Proposition chunking** — indexing atomic, self-contained factual statements with references resolved ("Albert Einstein was born in 1879") instead of passages (Dense X Retrieval); it raises recall for unsupervised retrievers but multiplies index size and drops qualifiers, so it works best as an extra representation pointing to the parent passage [24c].
- **PTU / provisioned throughput** — reserved model capacity billed regardless of use [31].
- **Pyroscope** — Grafana Labs' continuous-profiling database (CPU, memory, locks, down to the line of code), fed by language SDKs, Alloy's eBPF profiler or OTLP profiles; span profiles link a trace span to the samples taken while it ran [45b].
- **Quantization (AWQ, GPTQ, GGUF)** — storing weights at lower precision to cut memory and cost; the formats differ by runtime [16, 26].
- **RAG** — retrieval-augmented generation [24].
- **RAG-Fusion** — multi-query retrieval whose rankings, one per generated rephrasing of the question, are fused with reciprocal rank fusion before generation; it costs one generation plus N retrievals, and answers drift off topic when the generated queries do [24c].
- **RAG triad** — TruLens's three reference-free checks: context relevance (the query against each retrieved chunk), groundedness (the response against the context, claim by claim) and answer relevance (the response against the query) [24c].
- **RAGAS** — an open-source library of LLM-judged RAG metrics (faithfulness, answer relevancy, context precision and recall, noise sensitivity, factual correctness, tool and agent metrics) with knowledge-graph test-set generation; its 0.4 release changed the API, so pin the version and the judge model and calibrate against human labels [24c, 32].
- **RAGChecker** — a claim-level RAG diagnostic framework (Amazon, NeurIPS 2024) that checks response and ground-truth claims by entailment to report overall precision, recall and F1 plus retriever metrics (claim recall, context precision) and generator metrics (context utilization, noise sensitivity, hallucination, faithfulness), naming the module that failed [24c].
- **RAPTOR** — Recursive Abstractive Processing for Tree-Organized Retrieval: cluster chunk embeddings, summarize each cluster with an LLM and repeat to build a tree of summaries, then retrieve across all levels at once; it helps synthesis questions over long documents, but updates often force rebuilds [24c].
- **Rate / usage / mix variance** — the split of a cost variance once one-time and timing items are removed: rate is the price change on actual quantities, usage (volume) the quantity change at forecast prices, and mix the shift between items with different prices; the three add up exactly to the variance, and FX belongs to rate [47a, 47c].
- **Rate limit** — request or token caps per key; design with queues, backoff and routing to alternate capacity [31, 49].
- **ReAct** — reason-and-act loop interleaving thought, tool call and observation [22].
- **Realized savings** — a saving measured after the change against a counterfactual baseline chosen beforehand (pre-change unit cost × actual volume, the pre-change trend, rate × quantity, or a ratio), not against last month's bill; reported as run-rate, in-year and annualized figures net of one-time costs, and watched for decay [47a, 47e].
- **Recording rule** — a Prometheus rule that evaluates an expensive expression on a schedule and stores the result as a new series named `level:metric:operations`; used for busy dashboard panels, SLO ratios and alert inputs, at the aggregation level where they are read [45a, 45b].
- **Recurrent depth** — a model that iterates a block of layers a variable number of times on a latent state before decoding (Huginn, 3.5 billion parameters, 2025), so test-time compute grows with iterations rather than tokens; no production API exposes it [22c, 39b].
- **RED (rate, errors, duration)** — the request-centered monitoring method (Tom Wilkie, 2015): request rate, errors and duration for every service or endpoint, a subset of the golden signals that the Collector's span-metrics connector derives from spans [29b, 45b].
- **Red teaming** — adversarial testing of models and agents, automated with tools such as PyRIT, garak, promptfoo and DeepTeam [53, 53b].
- **Reinforcement learning from human feedback (RLHF)** — preference-based policy optimization with a reward model [26b].
- **Remote Control** — Claude Code feature to steer a session running on your own machine from claude.ai/code or the Claude mobile app [11, 52a].
- **Remote write** — the Prometheus protocol that streams samples from the write-ahead log to a long-term store such as Mimir in sharded, retried batches; if the destination is down longer than the WAL keeps data (about two hours), samples are lost, so alert on lag [45a, 45b].
- **Representation engineering** — finding population-level directions in a model's activations (honesty, harmlessness, power-seeking) by contrasting stimuli, then tracking a direction as a monitor or adding it to steer behavior; for anyone with access to the activations, the steering side is an attack surface [22c].
- **Representational collapse** — the failure of joint-embedding training in which the encoder outputs the same vector for every input (complete collapse) or uses only a few dimensions (dimensional collapse) while the loss looks healthy; caught by per-dimension variance, effective rank and a stalled probe, and prevented by negatives, an EMA target, variance–covariance terms or SIGReg [17, 17b].
- **Reserved Instances / reservations** — resource-based commitments to a resource type, usually in one region, for one or three years in exchange for a deeper discount than spend-based plans (AWS Standard and Convertible RIs; Azure reservations, up to 72%); an hour without matching usage is lost, and from February 2027 new Azure reservations for services covered by savings plans cannot be exchanged [47, 47e].
- **Resource (OpenTelemetry)** — the attributes describing what emits telemetry (`service.name`, `service.version`, `deployment.environment.name`, host, pod, region), attached once per batch; Prometheus maps service namespace and name to `job`, the instance id to `instance` and the rest to `target_info` [29b, 45b].
- **Reward hacking** — a model exploiting flaws in its reward or test signal instead of solving the task (special-casing inputs, editing tests, exiting before tests run); keep graders and tests outside the agent's write scope [26b, 53c].
- **Rightsizing** — matching instance or request size to measured demand: size to a high percentile of CPU and memory (P95 to P99.5) plus headroom over a lookback that covers the workload's cycle, consider family and generation, and restate the saving at effective rates, because a smaller fleet can leave commitments unused [47, 47e].
- **RLS (row-level security)** — database policies restricting rows by user [30].
- **RLVR** — reinforcement learning with verifiable rewards (tests, exact answers) rather than learned reward models [26b].
- **Rogue agent** — an agent acting against its principal's intent, whether from a misspecified goal, a learned disposition, subversion by injected content or a plain capability failure; OWASP's ASI10 [53c].
- **RRF (reciprocal rank fusion)** — rank-based fusion of result lists: each document scores Σ 1/(k + rank) over the lists that contain it, with k = 60 by convention; it needs no score calibration but discards score margins, and a tuned weighted sum of normalized scores can beat it when labels exist [18, 24c].
- **Rug pull** — an MCP server (or skill) that changes its tool descriptions after you approved it; pin versions or description hashes and re-approve on change [20b, 49, 53c].
- **Rule of Two (Agents Rule of Two)** — see Lethal trifecta / Agents Rule of Two [49, 62].
- **Sampling / Roots (MCP)** — client features through which a server asked the host's model for a completion, or learned which directories it may use; deprecated in the 2026-07-28 revision [20b].
- **Sandbox** — isolated execution for agent code and tools (container, microVM, network egress rules) [30, 52].
- **Savings Plans** — AWS's spend-based commitments: an hourly dollar commitment for one or three years at discounted rates, as Compute Savings Plans (up to 66%, across EC2 families and regions, Fargate and Lambda), EC2 Instance Savings Plans (up to 72%, one family in one region) or SageMaker AI Savings Plans; unused commitment in an hour is lost, and Azure's savings plan for compute is the counterpart [47, 47e].
- **Schema URL** — a URL recorded on each resource and scope block (such as `https://opentelemetry.io/schemas/1.44.0`) naming the semantic-convention version the data follows; its schema file lists renames between versions so tools can translate data, but it cannot express unit or meaning changes [29b].
- **Secrets and keys (Secrets Manager, Key Vault, Vault, KMS)** — where credentials and encryption keys live; never in prompts, repos or tool outputs [30, 57].
- **Seed / temperature / top-p** — sampling controls; low temperature and a fixed seed reduce, but do not remove, non-determinism [16, 54].
- **Self-query** — a model turns a question into a semantic search string plus a structured metadata filter ("laptops under \$1,000 released after 2024"); validate generated filters against allowed values, relax them when nothing matches, and never let permission filters come from the model [24c].
- **Self-RAG** — the model decides when retrieval is needed and critiques retrieved passages and its own draft for relevance and support (reflection tokens in the original paper) [24b, 24c].
- **Semantic cache** — serving a cached answer for a query whose embedding is near a previous one; a FinOps lever with a staleness risk [31].
- **Semantic chunking** — splitting documents where the embedding similarity of consecutive sentences drops rather than at fixed sizes; the evidence is mixed, so keep it only if it beats a recursive baseline on your recall set [18, 24, 24c].
- **Semantic conventions** — OpenTelemetry's registry of standard names, types, units and meanings for attributes, spans, metrics and events (`http.response.status_code`), each marked development, release candidate, stable or deprecated; the GenAI conventions are still in development, so pin the version you emit [29, 29b, 45a].
- **Semantic layer** — defined metrics/dimensions that make text-to-SQL reliable [21, 23].
- **Sequence-level distillation** — fine-tuning a student by ordinary likelihood on the teacher's generated outputs, which approximates matching the teacher's distribution over whole sequences (Kim and Rush, 2016); the only option with an API teacher, but the student never practices recovering from its own mistakes (exposure bias) [26b, 26c].
- **Serverless (Cloud Run, Lambda, Container Apps)** — scale-to-zero compute; good for spiky agent traffic, poor for long-lived GPU work [45].
- **SFT (supervised fine-tuning)** — training on (prompt, ideal response) pairs [26b].
- **Shadowing** — a tool or skill whose description overlaps another's and captures its routing, sometimes deliberately by a malicious MCP server [53c].
- **Showback / chargeback** — reporting cost to teams with no accounting entry versus posting it to their budgets and the general ledger through a journal entry; the FinOps Foundation treats neither as the more mature practice, and a chargeback file must reconcile to the bill [31, 47, 47a, 47d].
- **Shuffle sharding** — giving each tenant a random subset of partitions, ingesters, store gateways and rulers so one tenant's bad query or cardinality spike touches few others; with 4 of 50 partitions per tenant, two random tenants share none 71% of the time [45b].
- **SIGReg** — LeJEPA's anti-collapse regularizer: project embeddings onto many random directions and test each one-dimensional projection against a standard normal (the Epps–Pulley statistic), which by the Cramér–Wold theorem pushes the whole distribution toward an isotropic Gaussian; one weight, linear cost in batch size and dimension [17b].
- **Single-writer principle** — every metric series must have exactly one writer; two writers of one series, such as Collector gateway replicas computing the same span or cost metrics, produce rejected duplicates or a counter that keeps resetting, so add a replica label, route by service or compute in node agents [29b, 45b].
- **Skill** — a packaged instruction set with scripts that an agent loads on demand (see Agent Skills / SKILL.md); also unrelated meanings in Alexa, Watson and Bot Framework [28b, 52a, 60].
- **Sliding window** — a contiguous range that grows on the right and shrinks on the left, giving O(n) answers to longest, shortest or count questions about subarrays and substrings whose condition is monotone in the window [39d].
- **SLO / SLA / SLI** — the internal target for an SLI over a window (99.9% of valid requests over 30 days), the contract with credits and exclusions that should be looser than the SLO, and the measured ratio of good events to valid events, chosen from user journeys [29b, 45, 45a].
- **Soft targets (distillation temperature)** — a teacher's full output distribution, softened by dividing its logits by a temperature above 1 so that the probabilities of wrong but similar classes become visible; the soft loss is multiplied by T² to keep its weight stable, and temperature matters most for classifier teachers that are nearly one-hot [26c].
- **Span event** — a timestamped, named annotation inside a span, with attributes (a `retry.scheduled` event carrying the back-off delay); recording exceptions as span events is deprecated in favor of log-based events correlated with the span [29b].
- **Span kind** — a span's role in a remote interaction: SERVER handles a synchronous request, CLIENT makes one, PRODUCER and CONSUMER send and later process a message, INTERNAL has no remote side; backends pair CLIENT and SERVER spans to draw service graphs, and a remote model call is CLIENT [29b].
- **Span link** — a pointer from one span to another span context, possibly in another trace, used when one parent does not fit, such as a consumer span processing a batch from many producers; links added after a span starts are invisible to head samplers [29b, 45b].
- **Span status** — Unset (the default), Error or Ok: instrumentation sets Error when an operation failed and leaves success Unset, Ok is an application override, server spans are Error only on 5xx, and an intentional cancellation such as a stopped stream is not an error [29b].
- **Sparse autoencoder (SAE)** — a network that decomposes a model's activations into many sparse, often interpretable features without labels; strong for discovering what a model represents, while dense linear probes have proved more reliable as alarms [22c, 62].
- **Spawn depth** — how many layers of sub-agents may spawn further sub-agents; Claude Code allows three layers below the main conversation by default (`CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH`), and a depth cap bounds the height of an agent tree but not its spend [53c].
- **Specification gaming** — satisfying the letter of an objective while defeating its intent, such as editing the tests an agent is graded on; reward hacking is the training-time form [22, 53c].
- **Speculative decoding** — a small draft model (or extra decoding heads) proposes several tokens and the target verifies them in one pass, keeping the target's output distribution; the speedup depends on the acceptance rate, which distilling the draft on the target's outputs raises [16, 26c].
- **Speculative RAG** — a small specialist drafter writes several answers from different subsets of the retrieved documents in parallel, and a larger generalist verifies and picks one [24b, 24c].
- **Speech-to-speech model** — audio-in, audio-out model (Nova Sonic, Gemini Live, OpenAI Realtime) [17, 41].
- **Split charges (AWS Cost Categories)** — a Cost Categories feature that distributes a shared cost (support, a network hub) across target categories proportionally, by fixed percentages or evenly; the split shows only in Cost Categories views, not in Cost Explorer, Budgets or Cost Anomaly Detection [47b, 47d].
- **SR 11-7** — the 2011 US bank model-risk guidance, superseded by SR 26-2 on 17 April 2026 [46, 54b].
- **SR 26-2** — the Federal Reserve's revised model-risk guidance, issued jointly with the OCC and FDIC on 17 April 2026: risk-based, most relevant above \$30 billion in assets, keeps "effective challenge", and puts generative and agentic AI outside its scope [46, 54b].
- **SSE / WebSocket** — streaming transports for token-by-token and bidirectional audio delivery [41, 49].
- **Step-back prompting** — asking a more abstract question first, retrieving for both the original and the abstract question, and answering with both contexts labeled; it helps over-specific questions that are answered by passages stating a general rule or a full history [24c].
- **Storage tiering** — moving data to colder storage classes that cost less per GB stored and more per GB read, with minimum storage durations and sometimes minimum billable object sizes; it saves money on old, large, rarely read data kept past the minimums and loses it on small objects, bulk reads and early deletion [47, 47e].
- **Strands Agents** — AWS's open-source model-driven agent SDK [20].
- **Streaming** — delivering tokens as they are generated; cuts perceived latency and enables early stops [49].
- **Strong-to-weak distillation** — Qwen3's recipe for its small models: off-policy distillation on a large teacher's outputs in thinking and non-thinking modes, then on-policy distillation aligning the student's logits with the teacher's on the student's own responses, at about a tenth of the GPU-hours of the full post-training pipeline [26c].
- **Structured metadata (Loki)** — key-value pairs stored with each log line but not indexed, for high-cardinality fields such as trace or request ids; queried with a label filter after the stream selector and no parser, so stream labels stay bounded [45b].
- **Structured outputs** — schema-constrained model responses [49].
- **Sub-agent** — an agent invoked by another with isolated context [22, 52a].
- **Supervisor** — the coordinating agent in a supervisor/sub-agent topology [22].
- **Sustained use discounts** — Google Cloud's automatic discount of up to 30% for eligible Compute Engine series that run for much of the month; it does not apply to usage covered by CUDs, and current documentation limits it to self-serve billing accounts [47b, 47e].
- **SWE-bench / τ²-bench / LMArena** — a coding benchmark on real repositories; a tool-use benchmark with simulated users; a crowd-sourced preference leaderboard [60].
- **Synthetic data** — generated examples for training or evaluation; useful only when label-checked and diverse [26, 32].
- **System prompt** — the standing instructions that frame every turn; versioned like code [22].
- **Tag inheritance (Azure)** — an Azure Cost Management setting that copies subscription and resource-group tags onto usage records (not onto the resources) for the current month; it skips purchases and is the cheapest way to raise allocation coverage on Azure [47b, 47d].
- **Tagging policy compliance** — FinOps Foundation KPI: compliant cost ÷ taggable cost, measured strictly (exact key, lowercase, a value from the dictionary) and weighted by cost rather than resource count; above 90% is the suggested first target [47d].
- **Tail latency** — the slow end of the latency distribution (p99, p99.9); when a request fans out to N parallel backends, 1 − 0.99^N of requests wait on at least one backend's p99 (63% at N = 100), and agents fan out in time across sequential calls; mitigated by timeouts, hedged requests and fewer hops [29b, 45a].
- **Tail sampling** — deciding after a whole trace has been buffered, usually in a Collector gateway tier that receives every span of a trace (routed by trace id), so error, slow and expensive traces are kept with a random baseline; biased on purpose, so derive RED and cost metrics before it [29b, 45a, 45b].
- **Tempo** — Grafana Labs' trace store on object storage, queried with TraceQL; Tempo 3 (2026) replaced ingesters and the compactor with a Kafka-based write path, and its metrics-generator derives service-graph and span metrics [45a, 45b].
- **Text-to-SQL / text-to-Cypher** — translating questions into database queries, reliable only over a semantic layer or ontology [23, 25, 33].
- **TFT / Chronos / TimesFM** — the Temporal Fusion Transformer and two pre-trained time-series foundation models [17.9].
- **Thin slice / readiness gate** — one user group and one workflow taken end to end through real identity, data and systems, with draft-only or read-only actions behind a feature flag and weeks of shadow mode; and the checklist it must pass before wider rollout (improvement over the human baseline beyond the confidence interval, red-team findings closed, cost within budget at ten times pilot volume, rollback and kill switch tested, owners named) [54b].
- **Thinking budget** — tokens (or effort) allowed for a model's reasoning before answering [16, 39b].
- **Time horizon (METR)** — the length of tasks, measured in the working time a skilled human needs, that an agent completes with a given probability, usually 50%; METR found it doubling about every seven months since 2019, and reliable horizons are much shorter (the 80% horizon about a third of the 50% one under a constant-hazard model) [0, 62].
- **Token** — the sub-word unit models process and bill on [16].
- **Tool poisoning** — hidden instructions in a tool's description, metadata or results that the model follows; Invariant Labs' April 2025 demonstration made Cursor leak an SSH key [20b, 53c].
- **Tool schema** — the JSON schema that defines a tool's name, parameters and description; the model reads it, so write it for the model [20, 28b].
- **Tool search / code execution with MCP** — two ways to keep a large tool catalog out of the context window: the host loads tool definitions only when the model searches for a capability, or the agent writes a short program that calls tools and filters their results in a sandbox [20b].
- **Topological sort** — an ordering of a directed acyclic graph's nodes in which every edge points forward; computed with Kahn's algorithm or depth-first search with three-color marking, both O(V + E) [39d].
- **Trace / span** — a request's tree of timed operations: a trace is all spans sharing one trace id, and a span is one named, timed operation with a parent, kind, status, attributes, events and links; the unit of agent observability [29, 29b].
- **traceparent / tracestate (W3C Trace Context)** — the headers that propagate trace context between processes: `traceparent` carries the version, trace id, calling span id and flags (sampled, and random in Level 2), `tracestate` up to 32 vendor entries, including OpenTelemetry's sampling threshold; a proxy, queue or thread pool that drops them breaks the trace [29b, 45b].
- **TraceQL** — Tempo's query language: select spans by span and resource attributes and intrinsics (`span:duration`, `span:status`), combine span sets with structural operators (`>` for child, `>>` for descendant) and aggregate; TraceQL metrics compute time series from spans at query time [29b, 45b].
- **Trajectory** — the sequence of tool calls and decisions in an agent run; evaluated alongside outcomes [53].
- **Trie (prefix tree)** — a tree of characters in which each root path spells a prefix; insert and lookup cost the length of the word; used for autocomplete and multi-word grid search [39d].
- **Trigger accuracy (skills)** — how reliably a skill loads when a request needs it (recall) and stays out when it does not (precision), measured on should-trigger and should-not-trigger prompts; misfires are fixed mostly in the description, and it is measured separately from task success against a no-skill baseline [45a, 45c].
- **Tripwire / canary token** — a planted signal that only misbehaviour triggers: fake credentials, canary rows no task reads, honeypot tools such as `export_all_customers`, checksums on tests and graders; one hit justifies containment [53c].
- **TTFT / TPOT** — time to first token (queueing plus prefill, growing with uncached input) and time per output token, or inter-token latency (the decode speed); a call takes about TTFT + (output tokens − 1) × TPOT, and for agents the number to measure is time to first visible token [16, 29b].
- **Two heaps** — a max-heap for the lower half and a min-heap for the upper half of a set of numbers, sizes within one of each other; gives the running median in O(log n) per insertion [39d].
- **Two-person rule** — a second human must approve destructive or irreversible actions such as deletes, large payments or production changes [53b, 53c].
- **Two pointers** — two indices that move through a sequence (usually sorted) from both ends, or as read and write positions, discarding at least one candidate per step for O(n) passes [39d].
- **Two-tower model** — separate encoders for query and item enabling ANN retrieval in ranking systems [17].
- **Unallocated cost %** — cost with no owner ÷ total cloud cost; allocating from the account hierarchy first and tags second, with written shared-cost rules, keeps it low (below 10%, then below 5%, as working targets) [47b, 47d].
- **Unblended cost / net unblended cost** — AWS's line-by-line cost: rate × usage, with commitment fees appearing when charged (an all-upfront purchase on its purchase date) and negotiated discounts as separate negative lines or in the discount columns; net unblended subtracts those discounts and is the cash and invoice view [47a, 47b].
- **Union-find (disjoint sets)** — a forest that tracks connected components under merges; with union by size and path compression each operation costs nearly constant amortized time [39d].
- **Unity Catalog** — Databricks' governance layer for data, models, functions and vector indexes [21].
- **Unity Gateway** — Databricks' governance gateway for models, coding agents, MCP servers and tools (permissions, guardrails, spend caps, rate limits, payload logging), generally available since 4 August 2026; it succeeds the AI Gateway for serving endpoints, once branded Mosaic AI Gateway [14, 21, 30].
- **Uplift modeling** — predicting the treatment effect per individual rather than the outcome; who to target, not who will buy [17; Part 6].
- **USE (utilization, saturation, errors)** — the resource-centered monitoring method (Brendan Gregg, 2012): for every resource, the share of time it is busy, the work queued that it cannot yet serve, and its errors, such as GPU utilization, requests waiting for a KV-cache slot and ECC errors [29b].
- **Utilization (commitment utilization)** — used commitment ÷ total commitment: whether you use what you bought; programs usually target 95% or more on flexible spend-based plans, and a commitment pays for itself only above its break-even utilization [47, 47e].
- **V-JEPA 2** — Meta's video JEPA (June 2025): encoders up to about a billion parameters trained on over a million hours of video by predicting the embeddings of masked spatio-temporal tubelets; it leads image encoders by more than 20 points on motion-heavy benchmarks, trails them on appearance, and ships MIT-licensed weights [17, 17b].
- **V-JEPA 2-AC** — an action-conditioned world model: a frozen V-JEPA 2 encoder plus a predictor trained on under 62 hours of robot video to predict the next frame's embedding from past embeddings, the arm's state and its action; it plans toward a goal image's embedding and reached 65–80% zero-shot pick-and-place with human-supplied sub-goals, at about 16 seconds per action [17, 17b].
- **Variance bridge** — a table or waterfall that walks from forecast (or budget) to actual through sized drivers grouped as one-time and timing, rate, usage and mix, sorted by size, kept to about ten lines, with no "other" line above materiality [47c, 47f].
- **Vector database / vector store** — a store with ANN indexes and metadata filters: dedicated engines (Qdrant, Weaviate, Milvus, Pinecone), search engines with vector support (Vespa, OpenSearch), or pgvector in Postgres [18].
- **Vector Search (Databricks)** — Databricks' former name for AI Search [21].
- **Vertex AI** — Google's former name for the Gemini Enterprise Agent Platform, still seen in API names, SDKs and job descriptions [15, 39b].
- **Vertex AI Search** — Google's former name for Agent Search [15].
- **vLLM / SGLang (continuous batching, PagedAttention, RadixAttention)** — open-source serving engines; both batch requests continuously as they arrive; vLLM's PagedAttention pages the KV cache to avoid fragmentation, and SGLang's RadixAttention reuses cached prefixes shared across requests [16].
- **Voice stack (Twilio, LiveKit, Pipecat, Vapi, Retell, Deepgram, ElevenLabs, Cartesia)** — telephony, real-time transport, orchestration frameworks, hosted voice-agent platforms, and STT/TTS vendors [41].
- **VPC Service Controls** — Google Cloud perimeters preventing data exfiltration [30].
- **WAPE / MAPE** — weighted and plain mean absolute percentage error: WAPE (Σ|actual − forecast| ÷ Σ actual) weights errors by size and is the headline accuracy for spend forecasts, while MAPE averages per-series percentage errors, so a small series counts as much as a large one, and fails when an actual is zero; accuracy is often reported as one minus WAPE [17.9, 47c].
- **Webhook** — an HTTP callback from a service to your endpoint on an event; verify signatures and make handlers idempotent [28, 49].
- **Workflow (vs agent)** — predetermined steps with model-filled parts; the agent decides the path [22].
- **Workload identity** — cloud-native identity for running services instead of long-lived keys; it proves which process is calling, not for whom or on whose instructions, so an injected agent still presents a valid identity [23b, 30].
- **World model** — a model that predicts how an environment's state changes, usually given an action; agents use one to plan over imagined futures, to train policies in imagination (Dreamer), to generate synthetic data or to test policies in closed loop; pixel-space models render for people, latent ones such as JEPA predict for decisions [17, 17b].
