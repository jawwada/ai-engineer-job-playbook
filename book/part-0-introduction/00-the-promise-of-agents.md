# 0. The promise of agents: what is happening, who is winning, and how to read this book

> **What you need to be able to say:** what an AI agent is in one sentence, and why 2024–2026 made agents practical; what the best evidence says about productivity, including the studies that found no gain or a loss; where agents already do real work, from Kenyan maternity care to Japanese engineering teams; who has made money building them, and what their stories share once you correct for survivorship; and which path through this book fits your time. Every figure is dated and linked. Anything marked *(reported, verify)* or *(self-reported)* rests on one unaudited source: a lead, not a fact for an interview.

## 0.1 What an agent is, and why it became practical in 2024–2026

An **AI agent** is a language model running in a loop with tools. It reads a goal, chooses an action (search, query a database, run a test, edit a file, call an API), observes the result and decides the next step, until the goal is met or a budget runs out. A chatbot answers; an agent acts, checks and continues. Chapter 22 draws the finer line between *workflows* (your code decides the path) and *agents* (the model decides it).

The loop is not new. What changed in 2024–2026 is that every part of it became good enough, and cheap enough, at the same time:

| Enabler | What changed | Dated evidence |
|---|---|---|
| A standard plug for tools | Function calling became routine, and the Model Context Protocol (MCP) gave tools and data sources one interface any agent can call | Anthropic released MCP in [November 2024](https://www.anthropic.com/news/model-context-protocol); when it was [donated](https://anthropic.com/news/donating-the-model-context-protocol-and-establishing-of-the-agentic-ai-foundation) to the Agentic AI Foundation, a directed fund under the Linux Foundation, in December 2025, it had more than 10,000 active public servers and 97 million monthly SDK downloads |
| Reasoning models | Models trained to "spend more time thinking" before answering plan multi-step work better and recover from failed steps | OpenAI's o1-preview, [September 2024](https://openai.com/index/introducing-openai-o1-preview/) |
| Harnesses | Products that wrap the loop with file access, a shell, permissions, memory and sub-agents | Claude Code launched as a research preview in [February 2025](https://www.anthropic.com/news/claude-3-7-sonnet), able to "search and read code, edit files, write and run tests, commit and push code to GitHub, and use command line tools"; a year later its run-rate revenue was above \$2.5 billion ([Anthropic](https://www.anthropic.com/news/anthropic-raises-30-billion-series-g-funding-380-billion-post-money-valuation)) |
| Cheaper tokens | Agents make many calls per task, so the price per call decides what is economic | Querying a model that scores like GPT-3.5 on MMLU fell from \$20 to \$0.07 per million tokens between November 2022 and October 2024, roughly 280-fold ([Stanford AI Index 2025](https://hai.stanford.edu/news/ai-index-2025-state-of-ai-in-10-charts)) |
| Longer reliable tasks | Each model generation completes longer chains of steps before it fails | METR found that the length of software tasks (in human working time) frontier models complete half the time had doubled about every seven months since 2019; Claude 3.7 Sonnet stood near 50 minutes in early 2025 ([Kwa et al.](https://arxiv.org/abs/2503.14499)) |

Demand followed. In April 2026 Google said its first-party models were processing more than 16 billion tokens per minute through customers' direct API use, up from 10 billion a quarter earlier ([Google](https://blog.google/innovation-and-ai/infrastructure-and-cloud/google-cloud/cloud-next-2026-sundar-pichai/)): software calling models, not people typing into a chat box.

## 0.2 The promise, and the evidence on both sides

The promise: work that needed a person at every step (writing and testing code, answering customers, drafting documents, processing forms) can be done by a person supervising agents, faster and more cheaply. The evidence is better than the skeptics say and worse than the marketing.

**Controlled studies.** Know these by heart; interviewers and skeptical executives cite them.

| Study | Setting | Result | The catch |
|---|---|---|---|
| [Brynjolfsson, Li and Raymond, *Generative AI at Work*](https://www.nber.org/papers/w31161) (*Quarterly Journal of Economics*, 2025) | 5,172 customer-support agents given an AI assistant in a staggered rollout | +14% issues resolved per hour; +34% for novice and low-skilled agents | minimal effect on experienced, highly skilled agents |
| [Peng et al.](https://arxiv.org/abs/2302.06590) (2023) | randomized trial: write an HTTP server in JavaScript with or without GitHub Copilot | the Copilot group finished 55.8% faster | one small, well-specified, greenfield task |
| [Cui, Demirer et al.](https://www.microsoft.com/en-us/research/?p=1148213) (*Management Science*) | three field experiments, 4,867 developers at Microsoft, Accenture and a Fortune 100 company | +26.08% completed tasks; +27–39% for recent hires and juniors, +8–13% for seniors ([MIT Sloan](https://mitsloan.mit.edu/ideas-made-to-matter/how-generative-ai-affects-highly-skilled-workers)) | output counted in tasks; code quality not observed |
| [Dell'Acqua et al.](https://mitsloan.mit.edu/sites/default/files/2023-10/SSRN-id4573321.pdf) (Harvard Business School, 2023) | 758 BCG consultants with GPT-4 | inside the model's competence: 12.2% more tasks, 25.1% faster, over 40% higher quality | on a task outside it, consultants using AI were 19 percentage points *less* likely to be right |
| [METR](https://metr.org/blog/2025-07-10-early-2025-ai-experienced-os-dev-study/) (July 2025) | randomized trial: 16 experienced open-source developers, 246 real issues in mature projects they knew, early-2025 tools (Cursor Pro with Claude 3.5/3.7 Sonnet) | **19% slower** with AI | they had forecast a 24% speed-up, and afterwards still believed AI had made them 20% faster |
| [Humlum and Vestergaard](https://www.nber.org/papers/w33777) (NBER, 2025) | Danish adoption surveys linked to administrative labor records | "precise null effects" on earnings and recorded hours, ruling out effects above 2% two years after ChatGPT's launch | measures pay and hours, not output; covers chatbots, not agents |

Together they say the gain is largest when the task sits inside what the model does well, when the output can be checked quickly, and when the person is less experienced or new to the material; experts in large, familiar codebases can be slowed down while believing the opposite. Hence the weight this book puts on measurement over impression (chapters 32 and 53).

**Adoption: near-universal use, scarce value.** McKinsey's [*The state of AI in 2026*](https://www.mckinsey.com/capabilities/quantumblack/our-insights/the-state-of-ai) (1,719 respondents in 97 countries, surveyed May–June 2026) found nearly nine in ten respondents reporting regular AI use in at least one business function, and 44% saying AI was scaling across their enterprise. Forty percent of respondents from large organizations reported scaling AI agents, up from 27% a year earlier; at smaller organizations the share stayed at 22%. Yet only 37% attributed any EBIT impact to AI, and "high performers" (5% or more of EBIT from AI, plus "significant" value) were 6% of respondents. A warning for software vendors: nearly a third said their organization had decided against buying a product or feature because it could be built in-house with agentic coding tools. [BCG](https://www.bcg.com/press/30september2025-ai-leaders-outpace-laggards-revenue-growth-cost-savings) (September 2025, 1,250 executives) classed 5% of companies as "future-built" and 60% as laggards with minimal revenue or cost gains, and estimated that agents produced 17% of AI's value in 2025, rising to 29% by 2028.

**Delegation is rising.** Anthropic's Economic Index found in [February 2025](https://www.anthropic.com/research/the-anthropic-economic-index) that 37.2% of Claude use was software and other computer and mathematical work, and that 57% of uses augmented a person while 43% automated the task. By [September 2025](https://www.anthropic.com/research/anthropic-economic-index-september-2025-report), "directive" conversations (hand over the task, take the result) had risen from 27% to 39% of Claude.ai use, and 77% of business use through the API showed automation patterns.

**Code is the leading indicator.** Alphabet said in [October 2024](https://blog.google/inside-google/message-ceo/alphabet-earnings-q3-2024/) that "more than a quarter of all new code at Google is generated by AI, then reviewed and accepted by engineers"; in [April 2026](https://blog.google/innovation-and-ai/infrastructure-and-cloud/google-cloud/cloud-next-2026-sundar-pichai/) Sundar Pichai said "75% of all new code at Google is now AI-generated and approved by engineers, up from 50% last fall". Satya Nadella said in [April 2025](https://techcrunch.com/2025/04/29/microsoft-ceo-says-up-to-30-of-the-companys-code-was-written-by-ai/) that 20–30% of the code in Microsoft's repositories was "written by software", and Anthropic cited an outside estimate in February 2026 that Claude Code was authoring 4% of all public GitHub commits. These show direction, not magnitude: each company counts differently, and none publishes its method.

**The counter-evidence.** Besides the METR trial, keep three results next to the good news.

- *Most pilots do not pay.* MIT NANDA's *GenAI Divide* report claimed that 95% of organizations saw no business return on \$30–40 billion of enterprise generative-AI spending ([Virtualization Review, August 2025](https://virtualizationreview.com/Articles/2025/08/19/MIT-Report-Finds-Most-AI-Business-Investments-Fail-Reveals-GenAI-Divide.aspx)). Its base (52 interviews, 153 survey responses collected at four conferences, and a review of 300-plus public initiatives) is thin, but the direction matches McKinsey's 6%.
- *Many agent projects will be canceled.* [Gartner](https://www.gartner.com/en/newsroom/press-releases/2025-06-25-gartner-predicts-over-40-percent-of-agentic-ai-projects-will-be-canceled-by-end-of-2027) predicted in June 2025 that over 40% of agentic AI projects will be canceled by the end of 2027 "due to escalating costs, unclear business value or inadequate risk controls", and estimated that only about 130 of the thousands of vendors selling agentic AI are real; many others are rebranding older products ("agent washing").
- *The entry-level squeeze.* On ADP payroll data through June 2026, [Brynjolfsson, Chandar and Chen](https://digitaleconomy.stanford.edu/app/uploads/2026/08/Canaries_August2026.pdf) found employment of 22- to 25-year-olds in AI-exposed occupations 19% below where it would be had it kept pace with less-exposed peers. The declines are concentrated where AI substitutes for tasks; where it complements workers, employment is flat or rising, especially for experienced ones.

The honest summary: agents already pay where the work is checkable and the workflow is redesigned around them, and most organizations have not done that yet. The gap between adoption and value is the job market this book is about.

## 0.3 Agents at work around the world: fourteen examples

Some are agents that act on their own; others are assistants that draft for a person. Both count: the measured outcomes so far come mostly from the assisted end, and the line moves every quarter. Vendor case-study figures are marked.

**Klarna (Sweden; fintech customer service).** Klarna's OpenAI-based assistant handles refunds, returns and payment questions in more than 35 languages. Klarna reported in February 2024 that in its first month it held 2.3 million conversations (two-thirds of its service chats, the work of about 700 full-time agents), cut resolution time from 11 minutes to under 2, and would add an estimated \$40 million to 2024 profit ([OpenAI](https://openai.com/index/klarna)). In May 2025 chief executive Sebastian Siemiatkowski told Bloomberg that the AI-first approach had been cheaper but produced "lower quality", and Klarna began hiring people again so that customers could always reach a human ([Entrepreneur](https://www.entrepreneur.com/business-news/klarna-ceo-reverses-course-by-hiring-more-humans-not-ai/491396)). Both halves are the lesson.

**Octopus Energy (United Kingdom; energy customer service).** Arlo, built with Octopus's Kraken platform, answers routine customer emails (tariff renewals, payment dates, account details) on its own, labels every reply as AI-written, and routes vulnerable customers and complex complaints to people. In a three-month trial it handled about 8,000 emails a week, 4% of the total, scoring 76% customer satisfaction against 72% for comparable human replies ([Octopus Energy, July 2026](https://octopus.energy/press/more-news-press-releases/octopus-energy-s-ai-trial-wins-customer-approval/)).

**Verizon (United States; telecom service and sales).** A Gemini-based assistant drawing on nearly 15,000 internal documents sits on the screens of Verizon's 28,000-person customer-service team and helps reps find the right answer. Verizon told Reuters in April 2025 that sales through that team had risen nearly 40% since deployment, as service reps turned into sales reps ([Reuters via AOL](https://www.aol.com/news/verizon-says-google-ai-customer-120648406.html)).

**Kaiser Permanente (United States; healthcare).** Ambient "AI scribes" listen to the consultation and draft the clinical note. Over 63 weeks to December 2024, 7,260 Permanente physicians used them in about 2.58 million encounters, saving an estimated 15,791 hours of documentation (about 1,794 eight-hour workdays); 84% reported a positive effect on their communication with patients ([AMA](https://www.ama-assn.org/practice-management/digital-health/ai-scribes-save-15000-hours-and-restore-human-side-medicine); [Permanente](https://permanente.org/analysis-ai-scribes-save-physicians-time-improve-patient-interactions-and-work-satisfaction/)).

**Intuit QuickBooks (United States; small businesses).** In July 2025 Intuit put agents inside QuickBooks for bookkeeping, customer follow-up, finance and payments. The payments agent predicts late payers and creates, sends and chases invoices; Intuit says businesses using it are paid five days faster on average (company claim, [Accounting Today](https://www.accountingtoday.com/news/intuit-debuts-ai-agents-for-quickbooks)).

**The UK civil service and Pennsylvania (government).** In a three-month trial, more than 20,000 UK civil servants using Microsoft 365 Copilot reported saving 26 minutes a day, nearly two working weeks a year ([GOV.UK, June 2025](https://www.gov.uk/government/news/landmark-government-trial-shows-ai-could-save-civil-servants-nearly-2-weeks-a-year)). In Pennsylvania, 175 employees in 14 agencies piloting ChatGPT Enterprise reported saving 95 minutes a day on drafting, summarizing and navigating procedures ([Governor's Office, March 2025](https://www.pa.gov/governor/newsroom/2025-press-releases/-shapiro-administration-leads-the-way-in-ethical-use-of-ai)). Both figures are self-reported, the measurement weakness the METR trial exposed.

**Kisan e-Mitra (India; agriculture and government).** The Ministry of Agriculture's voice-enabled chatbot answers farmers' questions about PM-KISAN income-support payments (eligibility, registration status, delayed installments) from the scheme's beneficiary records, in 11 languages. Launched in September 2023, it was answering more than 20,000 queries a day by April 2025, with over 9.2 million answered in total ([Apolitical](https://apolitical.co/en/navigator/case-studies/kisan-e-mitra-indias-voice-enabled-ai-support-for-farmers)).

**Nubank (Brazil; banking software).** Nubank needed to migrate an ETL monolith of more than six million lines, a job scoped at 18 months for over 1,000 engineers. It fine-tuned Cognition's Devin on migrations engineers had completed by hand, then had it migrate sub-modules in parallel while engineers reviewed and merged the changes. Cognition reports an 8–12× gain in engineering efficiency and over 20× cost savings (vendor claims, [Devin](https://devin.ai/customers/nubank)).

**Mercado Libre (Latin America; e-commerce).** Its internal platform, Verdi, lets 17,000 developers build model-powered features across more than 30,000 microservices. Verdi began handling 10% of customer-service mediation within months, model review of listings raised fraud-detection accuracy to nearly 99% for flagged items, and vision models let the company catalog 100 times more products (vendor claims, [OpenAI](https://openai.com/index/mercado-libre/)).

**Jacaranda Health (Kenya; maternal healthcare).** PROMPTS is an SMS service for pregnant women and new mothers that works on basic phones, in English, Swahili and Sheng. A model flags about 7% of incoming messages as potentially urgent (signs of pre-eclampsia, a jaundiced newborn) for a team of 18 nurses who call back at once and audit the service around the clock. NPR reported in September 2026 that it serves about 700,000 users a year across 24 counties, handles about 15,000 messages a day, and costs the nonprofit about \$2 per user per year ([NPR via KPCW](https://www.kpcw.org/npr-news/2026-09-17/to-prevent-deaths-in-childbirth-kenyan-moms-turn-to-an-ai-powered-chatbot)).

**Digital Green's Farmer.Chat (Kenya, India, Ethiopia, Nigeria; agriculture).** A retrieval-augmented assistant over agricultural videos, call-center logs and crop fact sheets, reached through WhatsApp or Telegram by text, voice or photo. Its 2024 paper reported more than 15,000 farmers and 300,000 queries in six languages across 40-plus crops, with about 75% of queries answered successfully ([arXiv](https://arxiv.org/html/2409.08916v2)); Digital Green's early estimate is a cost of extension advice of \$0.35 per farmer instead of \$35 ([OpenAI](https://openai.com/index/digital-green)).

**DBS Bank (Singapore; banking).** DBS reports more than 2,000 models across over 430 use cases delivering about S\$1 billion of economic value in 2025 ([annual report](https://www.dbs.com/annualreports/2025/letter-from-chairman-ceo.html)), up from S\$750 million in 2024 ([DBS](https://www.dbs.com/artificial-intelligence-machine-learning/artificial-intelligence/singapore-finTech-festival-2025-powering-dbs-next-phase-of-growth-with-ai.html)). The other side: in February 2025 its then chief executive said DBS would shed about 4,000 contract and temporary roles over three years as AI took over the work, with permanent staff unaffected ([Bloomberg](https://news.bloomberglaw.com/banking-law/dbs-sees-job-cuts-of-4-000-temp-staff-as-ai-replaces-roles-1)).

**Rakuten (Japan; software).** Rakuten engineers run several Claude Code sessions in parallel, from unit tests to pull-request review. In one trial Claude Code worked autonomously for seven hours implementing a method inside vLLM, a 12.5-million-line open-source library, reaching 99.9% numerical accuracy against the reference; Rakuten reports cutting time to market for new features from 24 working days to 5 (vendor case study, [Claude](https://www.claude.com/customers/rakuten)).

**Voice creators on ElevenLabs (worldwide; individual creators).** Voice actors and other creators license professional clones of their own voices on ElevenLabs' marketplace, on terms they set, and are paid whenever a customer generates audio with them. By May 2026 more than 10,400 creators had earned over \$22 million, double the \$11 million paid out by November 2025 (company figures, [ElevenLabs](https://elevenlabs.io/blog/22-million-earned-by-voice-creators-on-elevenlabs)).

### Survivorship bias, and the cautionary tales

Every table like the one above is a list of survivors. Gartner's estimate that only about 130 of thousands of "agentic AI" vendors are real, and MIT NANDA's 95%, describe the denominator these stories hide. Three more corrections. Run-rates are annualized peaks, not audited revenue. Revenue built on someone else's tokens does not come with a margin: The Information reported in April 2026 that Cursor's run-rate had passed \$2.7 billion, "helping margins turn positive" ([Techleap summary](https://finder.techleap.nl/news/feed/cursor-hits-2-7b-revenue-run-rate-as-spacex-acquisition-looms); reported, verify). And an exit is not final until regulators agree, as Manus found.

The failures teach as much as the wins:

- **Builder.ai** raised more than \$450 million, with Microsoft among its backers, to sell AI-based app building. It entered insolvency in May 2025 after cutting its revenue estimate for the second half of 2024 by 25%, amid reports that its platform relied heavily on human engineers ([TechCrunch](https://techcrunch.com/2025/05/20/once-worth-over-1b-microsoft-backed-builder-ai-is-running-out-of-money/)).
- **Humane** raised more than \$230 million for the AI Pin, a wearable meant to replace much of the smartphone. HP bought most of its assets for \$116 million in February 2025, and the pins stopped working on 28 February 2025 ([TechCrunch](https://techcrunch.com/2025/02/18/humanes-ai-pin-is-dead-as-hp-buys-startups-assets-for-116m/)).
- **Presto Automation** sold AI voice ordering for drive-throughs. In January 2025 the SEC found that it had not disclosed that its first deployed units ran on a third party's speech technology, nor how many orders needed a human: over 70% on its newer version, and all of them at most locations using the original ([SEC order](https://www.sec.gov/files/litigation/admin/2025/33-11352.pdf)). The order was cease-and-desist only, but the lesson stands: the human-in-the-loop share is a metric to disclose, not a secret to keep.
- **Klarna** (section 0.3) showed that "the agent handled it" and "the customer was helped" are different measurements.

## 0.5 What the winners have in common, and what it means for you

Read sections 0.3 and 0.4 side by side and six patterns repeat.

1. **A painful, frequent workflow with a checkable output.** Code that passes tests, a ticket closed, a deck rendered, an invoice paid. The productivity studies predict exactly this: gains concentrate where output can be verified quickly.
2. **Speed of shipping.** Base44 went from start to sale in six months; Lovable reached \$75M ARR in seven months with 45 people; Bolt reached about \$40M in five months with fewer than 20. Small teams iterating daily on a narrow product beat large teams planning a broad one.
3. **Distribution built into the product.** Gamma's decks travel as links; apps built on Lovable draw 900 million visits a month; Cursor and Claude Code sit where developers already work; Verizon's assistant sits on the rep's existing screen. Nobody in the table won on model quality alone.
4. **Data and feedback loops.** Nubank fine-tuned Devin on its own finished migrations; Jacaranda's nurses audit the triage model around the clock. The loop that turns corrections into better behavior is the asset a competitor cannot copy.
5. **Pricing that survives the token bill.** Every agent run pays for model calls, so revenue can grow faster than margin. Manus counts usage-based revenue alongside subscriptions; Cursor and Lovable built in-house models; Cursor's reported path to positive margins shows why that matters. Chapter 31 has the arithmetic.
6. **Humans in the loop, disclosed.** Octopus routes vulnerable customers to people; Google's 75% is code "approved by engineers"; Nubank's engineers review every change. Presto and Builder.ai show what happens when the human share is hidden.

What this means for you: the scarce skill is not prompting; it is making an agent reliable inside a real workflow. That means choosing the pattern (chapter 22), wiring tools through MCP (20b), retrieving the right context (24, 24b), evaluating honestly (32, 32b), securing the system (30) and keeping it affordable (31). That is the AI engineer's job in 2026 (chapter 44), and a founder's too. For early-career readers the payroll data is a warning and a direction: entry-level work that agents can substitute for is shrinking, while work that directs and checks agents is not. Your portfolio should show you building and evaluating agents, not only using them (chapter 57).

The book is meant to be used, not read cover to cover. Part 1 is a working system; the other parts give you what you need to explain it, extend it and get paid for it.

**Three reading paths.**

*The job seeker in a hurry (one week).* Build and run the agent first (Part 1), so applications go out while you study. *The interview in two weeks.* Days 1–2: chapters 35, 36 and 37 for the process and the target. Days 8–10: chapters 39 and 40 out loud, plus 39b–39c, 41 or 42 if the job matches them. Days 11–13: chapters 38 and 43, timed. Day 14: rest, then reread your own resume with chapter 55 beside it.
