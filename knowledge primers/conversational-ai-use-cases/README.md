# Conversational AI Use Cases — a Dialogflow primer and five worked designs

An interactive, single-file page on Google's conversational stack as it stands in October 2026 — Conversational Agents (Dialogflow CX) with flows and playbooks, and CX Agent Studio, its ADK-based successor inside Gemini Enterprise for Customer Experience — followed by five worked designs that apply the same rules. The layout is the one used across the other primers: a row of cards is the index, one card opens at a time, each card has tabs. Primer cards have six tabs (**Concepts** with a diagram or chart, **Example**, **Method**, **Pitfalls**, **Code**, **Say it in the room**); use-case cards have seven (**Scenario** with a page map, **Data**, **Design**, **Method**, **Pitfalls**, **Code**, **Say it in the room**). Open `conversational-ai-use-cases.html` in any browser; no build step, no network needed beyond the Google Fonts link (the page falls back to system fonts without it).

## Conventions

- Every design is a design study, not client work; every number in an example is marked `illustrative` unless a document is named beside it.
- Product names, prices, the model list, speech settings and compliance programmes were read in Google Cloud's documentation and price list on 19–20 October 2026 (chat $0.007 per flow request and $0.012 per playbook request; voice $0.001 and $0.002 per audio second; playbook models gemini-2.5-flash, gemini-2.5-flash-lite, gemini-3.1-flash-lite, gemini-3.5-flash-lite; CX Agent Studio GA 4 Feb 2026, agents-as-tools GA 24 Sep 2026, custom voices 12 Oct 2026). Verify before quoting in a later month.
- Passenger-rights, consumer-finance and clinical rules (the DOT automatic-refund rule, EU261 and its 2026 revision, Regulations E and Z, HIPAA, prescription rules) are paraphrased for design from the sources named on the Map card; counsel and clinicians own them. The designs keep every such fact in a versioned table or engine, never in a prompt.
- The two data charts (voice-turn timeline; cost per thousand conversations against playbook share) use the validated two-colour palette shared with the other primers, one axis per panel, a legend for two series and hover titles on marks.
- Code samples are sketches in Python (FastAPI, the Dialogflow CX client library, LangGraph), JSON agent-export excerpts, OpenAPI and SQL; library paths and arguments change, the shapes are what matter.
- No personal rate appears on the page.
- The page is a hosted Claude artifact as well; this file is the standalone copy for the repository.
